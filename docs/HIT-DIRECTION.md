# 实际受击的来向提示

主角受到有明确方向的真实伤害后，身体外侧出现一个短暂的浅红描边记号，指向来袭的一侧。它记录该次命中的投射物飞行／攻击方向；主角随后转身不会改变这一记录，记号随主角和原相机移动。

## 规则

- 只有实际生命损失才产生提示，沿用原减伤与致死伤害封顶后的扣血回执。无敌闪避、安全训练、零伤害或已倒地后的接触不新增提示。
- 使用命中时已有的有效方向数据。没有方向的暑热／寒冷伤害、零向量或无效数据不生成方向。高原风害有实际风向时可显示迎风一侧；范围攻击使用其原先锁定的攻击来向。
- 最新一次真实扣血决定提示。新的无方向扣血也会结束较旧来向的显示，避免把旧方向当成新伤害的来源。
- 显示寿命与浅红扣血数字同为0.7秒，最后0.2秒淡出。记号本身不闪烁、旋转或扩大；最低特效和减少动态保留。
- 位置沿用主角完整身体范围，留出间隔；屏幕边缘会整体平移以保留完整描边。HUD覆盖时仍可见，相交面板沿用原有淡化。记号没有按钮或交互区域。
- 菜单、应用暂停与训练时隐藏；恢复世界后使用剩余寿命。旅行、读档、新游戏沿用原清理规则。致死接触仍可显示本次来向。

## 工程与验证

来向存于原有临时`damageTaken`效果的`direction`中，没有新增存档字段、数值规则、输入、图片或字体。扣血数字、浮字排布、动画、伤害、耐力与无敌计时保留。

`python3 tools/run_hit_direction_core_checks.py` 检查真实命中数据、保护状态及旧档边界；`python3 tools/run_damage_taken_checks.py` 驱动生产Update／OnGUI，验证原承伤反馈与方向记号的几何、绘制顺序、淡出、设置、输入与生命周期。可用隔离的旧生产源码获得语义负向证据，并导出实际绘制命令作离线目检。
