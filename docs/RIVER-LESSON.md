# 老潮的河岸练钓 / Old Tide's river lesson

完成老潮原有的三条银鳍鱼委托，并找回第一枚星核后，镇中老潮的原菜单末尾新增「河岸练钓」。这是一条可选的生活任务：给孩子们的鱼汤准备好后，老潮请主角观察两种水流，带回亲手练习的记录。原湖畔垂钓、鱼汤委托、炉火共餐及其选项顺序和报酬保留。

## 玩家流程

1. 在镇中湖边向老潮接取记录；手帐新增第二页的「老潮的河岸记录」，可追踪并查看目的地。原二十项任务的身份与索引保留。
2. 到旧路河岸的「西侧水边」与「河岸流水」，靠近钓点按 E／手柄 B 交互后选择开始。两处都在原有可行走岸地上，不要求打开桥梁或根障，不改变旧路线。首次进入河岸时，正在追踪的练钓任务会继续保留。
3. 每轮先等候 1 秒，再有 1.6 秒的收线机会。浮标进入青绿色区时按 E、空格、手柄 A 或点击收线，随后放松钓线 0.55 秒。每轮只接受一次收线；等候和放松时按键不计分，错过整轮收线算一次失误。
4. 三次成功获得银鳍鱼 1、最多硬币 4，并照常推进捕鱼赏金；三次失误结束本次尝试，没有鱼饵或物资损失。成功钓到鱼才记下该钓点；金色标识变为薄荷色。鱼存放已满时不能开始或结算，不虚报记录。
5. 两处各钓成一次后，回镇中老潮身边交回记录，领取一次性的炖汤 2、山野议会声望 +1。不会收走钓到的鱼；炖汤空间不足时暂不完成，腾出空间后可再交付。完成后仍可在两处自由练钓。

湖畔与河岸共用收线输入入口：同一帧同时按下键盘、手柄或收线按钮，只接受一次收线意图，避免湖畔重复计成功或失误。下一帧的新按键仍立即生效，不增加冷却，也不改变浮标速度、判定区、河岸阶段时长或原奖励。

## 存档与集成

- 持久进度只追加 `riverlesson_accept`、`riverlesson_site_0`、`riverlesson_site_1`、`riverlesson_complete` 标记，不新增 SaveData 字段或更改存档版本。v1/v2 旧档只有已满足条件的邀请，没有自动接取、捕获或报酬。
- 进行中的阶段与收线次数属于临时状态，不写入存档。自动保存不会打断当前尝试；读档、旅行、关闭或切换菜单会取消尝试，重新开钓从零开始。未钓成的次数不能凭旧回调结算。
- 实际接取、开钓、收线与交付均重新校验地点、距离、原交互对象、存档与世界归属、存活及安全状态。附近敌人、敌方投射物或危险区域会阻止开钓。钓鱼时世界暂停，沿用原湖畔规则。
- Campaign 只在旧路河岸对象列表末尾追加两个非阻挡互动点；原地图格、装饰、交互物坐标/顺序与所有 Boss 数据保留。钓点使用既有鱼图标，不新增或替换人物、美术、字体、场景资源。新中文文案使用现有字体可显示的字形。

- `python3 tools/run_river_lesson_core_checks.py`：六组生产 Core 检查，覆盖原三次湖畔捕获和委托、实际阶段与两端收线边界、超时和重复输入、两处记录、原任务索引与地形、一次性/满库存报酬、旧档和临时状态归属。完整 Core 回归也包含这六组。
- `python3 tools/run_river_lesson_checks.py`：四组离线生产 Runtime 检查，走实际 Update/OnGUI、E/数字菜单、手帐第二页、WASD 路径、键盘/手柄声明/鼠标收线、超时/取消、SaveStore 与地图标记。`--capture-dir` 可导出双语、正常/大字、960/1280 窗口的界面记录。
- `python3 tools/run_fishing_input_checks.py`：钓鱼输入专项，通过生产 Update/OnGUI 核对多种收线输入合并、后续新按键与原钓鱼结算；`--baseline-ref` 可对固定旧提交运行相同检查，区分编译失败与实际行为失败。
- 定向回归覆盖旧路河岸、导航交互、路标、手帐分页、原共餐与厨房/补给。七阶段编译使用已安装 Unity 2022.3.53f1 的真实 DLL，包含隔离的 Player Core/Runtime。
