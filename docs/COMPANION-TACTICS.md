# 同伴战术手册与施放反馈

按C打开「同行伙伴」，点击每位同伴下方的指令说明。三个页签可先查看尚未招募者的能力，不会招募、替换同伴、消耗物资或发出指令。返回、手柄B和LB／RB沿用原菜单导航。原邀请、个人故事、赠礼与独行操作保留。

## 说明来自实际战斗参数

所有指令仍在Z／RB或原HUD按钮触发后准备0.20秒，于真实联系帧释放，完整动作0.52秒。冷却从接受指令开始计算：通常18秒，共同治理结局为12秒。

| 同伴 | 实际指令 |
| --- | --- |
| 米拉 | 生命恢复18＋羁绊×3、耐力恢复15，均受上限限制；防护至少3秒，使防护这一项的伤害倍率为0.45，即减伤55%。不增加吸收伤害的额外生命。 |
| 伊沃 | 三发贯穿箭，单箭基础伤害为起手时主角伤害×（0.8＋羁绊×0.05）。沿起手方向和目标点，从同伴实际位置发射；墙体、护甲、暴击与实际接触继续使用原规则。发射三箭不代表三次命中。 |
| 森 | 释放时在主角所在位置建立固定的4格领域，4秒内五次脉冲，每次基础伤害为起手伤害×0.4；另对5格内且未被墙体阻隔的敌人施加初始控制。领域命中会重写受控时间，不能把1.4秒初始控制理解成所有目标连续冻结1.4秒。 |

手册的伤害数字反映当前配置与状态；实际攻击锁定起手数值。原自动支援、跟随、动画、命中、掉落归属和任务进度规则不变。

## 真实施放回执

世界HUD在准备期间显示同伴姓名与准备状态。只有`ReleaseCompanionCommand`真实释放后，才出现约2.2秒的确认：米拉本次实际恢复的生命／耐力（不会把溢出治疗算入）、伊沃实际发射的箭数、森领域已生成及初始受控敌人数。不覆盖任务或剧情通知，不额外制造伤害浮字或特效。

这条信息只读，鼠标可穿透它瞄准攻击；危险经过时沿用原HUD淡化和轮廓补绘。低特效与减少动态仍保留文字。原指令槽在就绪时使用简短招式名，冷却中继续显示真实剩余时间。

菜单与应用暂停冻结反馈；训练、死亡、换地区、读档、新游戏、换同伴会清除本次回执。短HUD确认消失后，同一会话的最近回执仍可在手册查阅，直到下次指令或上述重置。回执不进入SaveData，不新增版本或迁移字段；打开手册不会改变当前生命、耐力、世界时间、随机数或战斗动作。

## 验证与限制

`python3 tools/run_core_tests.py`包含指令说明／回执的核心检查与全部成熟核心回归。`python3 tools/run_companion_tactics_checks.py`直接驱动生产Update／OnGUI，验证Z、RB、鼠标、原菜单操作、真实释放帧、暂停与存档、只读指针、危险遮挡及中英／大字界面。可用`--capture-dir`输出一次性离线画面记录，CI执行同一检查入口。

离线输入、重建预览与实际Unity程序集编译分别只证明其对应范围；原生Frontier运行、实体手柄、GPU画面、Player构建试玩与性能验收仍为 **`NATIVE_UNVERIFIED`**。
