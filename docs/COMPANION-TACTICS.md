# 同伴战术手册与施放反馈

按C打开「同行伙伴」，点击每位同伴下方的指令说明。三个页签可先查看尚未招募者的能力，不会招募、替换同伴、消耗物资或发出指令。返回、手柄B和LB／RB沿用原菜单导航。原邀请、个人故事、赠礼与独行操作保留。

## 说明来自实际战斗参数

所有指令仍在Z／RB或原HUD按钮触发后准备0.20秒，于真实联系帧释放，完整动作0.52秒。冷却从接受指令开始计算：通常18秒，共同治理结局为12秒。

| 同伴 | 实际指令 |
| --- | --- |
| 米拉 | 生命恢复18＋羁绊×3、耐力恢复15，均受上限限制；防护至少3秒，使防护这一项的伤害倍率为0.45，即减伤55%。不增加吸收伤害的额外生命。 |
| 伊沃 | 三发贯穿箭，单箭基础伤害为起手时主角伤害×（0.8＋羁绊×0.05）。沿起手方向和目标点，从同伴实际位置发射；墙体、护甲、暴击与实际接触继续使用原规则。发射三箭不代表三次命中。 |
| 森 | 释放时在主角所在位置建立固定的4格领域，4秒内五次脉冲，每次基础伤害为起手伤害×0.4；另对5格内且未被墙体阻隔的敌人施加初始控制。领域命中会重写受控时间，不能把1.4秒初始控制理解成所有目标连续冻结1.4秒。 |

手册的伤害数字反映当前配置与状态；实际攻击锁定起手数值。原自动支援、跟随、动画、命中、掉落归属和任务进度规则不变。

## 真实施放回执

世界HUD在准备期间显示同伴姓名与准备状态。只有`ReleaseCompanionCommand`真实释放后，才出现约2.2秒的确认：米拉本次实际恢复的生命／耐力（不会把溢出治疗算入）、伊沃实际发射的箭数、森领域已生成及初始受控敌人数。不覆盖任务或剧情通知，不额外制造伤害浮字或特效。

这条信息只读，鼠标可穿透它瞄准攻击；危险经过时沿用原HUD淡化和轮廓补绘。低特效与减少动态仍保留文字。原指令槽在就绪时使用简短招式名，冷却中继续显示真实剩余时间。

菜单与应用暂停冻结反馈；训练、死亡、换地区、读档、新游戏、换同伴会清除本次回执。短HUD确认消失后，同一会话的最近回执仍可在手册查阅，直到下次指令或上述重置。回执不进入SaveData，不新增版本或迁移字段；打开手册不会改变当前生命、耐力、世界时间、随机数或战斗动作。

## 实时防护倒计时

防护生效时，世界HUD在左侧远行餐下方的固定位置显示共享防护的剩余秒数与「受到伤害 ×0.45」，避开原通知、反击提示、试机指引、竞速计时、到达横幅和回归说明。这是防护这一项的倍率，仍与难度、天赋、遗物、远行餐等原倍率相乘，不代表无敌或额外生命。文字读取实际计时器与战斗参数；低特效、减少动态和中英文界面均保留，危险经过时背景淡化，鼠标可穿透瞄准攻击。

先锋基础Q在实际释放时提供3秒，第二战技提供4秒；米拉指令释放时把防护延长至至少3秒。沿用原来的共享计时规则，包括基础Q可以覆盖较长防护，不叠加独立倒计时。准备期间不预报已获得防护，防护结束便隐藏。菜单、应用暂停、死亡和安全训练中不显示；世界暂停与命中停顿沿用原计时规则。显示不改变动作、伤害、资源、存档字段或重置行为。

## 自动攻击跟随锁定

V／手柄 R3 的现有目标锁定也用于同伴的下一次自动攻击。目标必须仍然存活、位于当前敌人列表内，并在同伴自身位置的原7格射程内、没有被墙体挡住；玩家看得见不代表同伴看得见。没有合适锁定时，自动攻击选择同伴周围最近的有效活敌，等距按敌人身份稳定选择。

此选择只发生在自动攻击准备前。X／L3轮换目标、解除锁定或目标之后移动，都不会改写已经准备的方向、目标点、伤害配置或飞行弹丸。弓箭和星火仍有真实飞行与阻挡，选中目标不保证命中。米拉生命支援的原80%判断优先于选敌；自动攻击的原间隔、伤害、准备／释放时间，以及Z／RB主动指令规则不变。不增加存档字段。

没有有效攻击目标、米拉也无需治疗时，空待不再消耗整段自动支援间隔。初次同行仍等待原1秒；就绪后，目标进入同伴自身射程且视线可达，或米拉需要治疗，才开始实际准备并计入原支援间隔：伊沃2.8秒，米拉与森6秒。仍在冷却时不会因目标出现而提前出手，原0.16秒接触、0.42秒动作、伤害、羁绊治疗量与手动指令优先规则保留。

## 近就绪轻点预输入

Z／RB与两种世界HUD布局支持冷却最后0.12秒的单次请求，先显示「等待指令」，到期才进入上述完整准备。等待期间原冷却、自动支援与回执继续，不能视为已经治疗或射箭；按下时的方向与目标点会保留，玩家自己的闪避／战技／攻击输入独立运行。菜单、换人、旅行、读档与训练边界不保留旧请求，存档结构不变。详见 [COMPANION-COMMAND-BUFFER.md](COMPANION-COMMAND-BUFFER.md)。

## 验证与限制

`python3 tools/run_companion_focus_core_checks.py`验证选敌、同伴视线／射程、原治疗／出手规则与快照连续性。`python3 tools/run_companion_focus_checks.py`直接驱动锁定与轮换输入、真实自动出手、暂停及只读手册。旧生产源码可作为基线编译同一测试，以断言失败而非编译错误复现原缺口。

`python3 tools/run_core_tests.py`包含指令说明／回执的核心检查与全部成熟核心回归。`python3 tools/run_companion_tactics_checks.py`直接驱动生产Update／OnGUI，验证Z、RB、鼠标、原菜单操作、真实释放帧、暂停与存档、只读指针、危险遮挡及中英／大字界面。可用`--capture-dir`输出一次性离线画面记录，CI执行同一检查入口。

`python3 tools/run_guard_status_checks.py`专项验证防护的真实Q／米拉释放、共享计时与消失、只读绘制及存档、鼠标穿透和危险遮挡，并记录双语与大字界面；它使用生产Update／OnGUI与离线Unity声明。

离线输入、重建预览与实际Unity程序集编译分别只证明其对应范围；原生Frontier运行、实体手柄、GPU画面、Player构建试玩与性能验收仍为 **`NATIVE_UNVERIFIED`**。
