# 危险边界的前景可读性

本轮基线 `1737c65`；恢复点 `refs/codex/checkpoints/threat-contours-baseline-1737c65`。

普通敌人、原有 Boss 和环境危险的原始预警在景物之前绘制。树冠、角色与复杂地面会掩盖预告；原 HUD 补绘只解决面板覆盖，未覆盖正常战场的景物遮挡。

新增一层静态危险轮廓，在景物、角色与氛围之后绘制。地面原有填充、收缩进度与倒计时保留。轮廓先画整条 7 像素暗底，再画整条 3 像素亮芯，避免相邻线段暗底盖掉亮芯。HUD 相交时复用同一套轮廓；最低特效和减少动态效果均保留，不额外闪烁或使用独立时钟。

- 追猎者：原 `EnemyMeleeRadius/EnemyMeleeCosine` 扇区及两条径向边。
- 射手：原四方向弓口、武器高度和锁定终点的射线。
- 重甲与八地原 Boss：原目标和 `EnemyAreaRadius`，使用招式已经承诺的阶段。
- 潮汐、玻璃、裂隙和档案冲水：原 `Hazard.position/radius` 与既有危险配色。

守望者、供水试机和横风的专用几何保留。轮廓不改判定、伤害、计时、闪避、输入、存档或主角外观；取消攻击、离开世界状态、死亡和对练结算时不保留新的轮廓。视口外轮廓被剔除。

真实攻击范围与 HUD 的视觉包络分别处理：`EnemyWarningBounds` 仍精确对应原范围；新描边的外伸量仅参与面板淡化和补绘，不扩大攻击。已有 Boss 承诺阶段、近战33点与环境48点检查保留。

新增命令：

```sh
python3 tools/run_threat_contour_checks.py --capture-dir .starfall-checks/layout
```

该检查执行生产 Core/OnGUI 与离线 Unity 声明，核对完整世界排序、HUD、实际几何、低特效、状态清理和真实到期伤害。离线预览仅重建绘制记录，不能替代 Unity GPU 画面。
