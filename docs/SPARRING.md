# 艾妲的战术训练 · Ada's Tactical Sparring

在余烬镇靠近教官艾妲 `(11,14)`，按 E 交谈，再选择新增的第三项「战术训练」。原先的基础木桩教学与首次报酬保留。完成基础三步教学，或取得第一枚星核后，可开始三段真实战斗。

| 训练 | 练习重点 |
| --- | --- |
| 追猎者 | 观察扑击预告，侧向闪避，再回身反击 |
| 重甲 | 比较正面护甲与绕后攻击，尝试打断准备中的攻击 |
| 射手与追猎者 | 避开箭路，选择目标，留出退路 |

使用当前职业、装备与武器打法，攻击、Q、闪避和敌人预告沿用正式战斗规则。三职业都可清场；反击、破势与绕后次数只提供记录，不是通关配额。HUD 同时记录受击次数与本次训练时间。计数来自实际命中，包括飞行中的反击箭；空挥不会计分。

受击仍有动作反应、击退与短暂无敌，但不扣生命。每段开始补满耐力；同伴不出战。世界时钟暂停，种植、餐效、凉茶和潮汐不会因训练消耗时间。炖汤、凉茶及探索能力沿用训练禁用规则。训练敌人不掉物资，不增加经验、熟练度、击杀统计、悬赏或故事进度。

每段清场后停留在结果面板，玩家自行开始下一段：E、Enter、手柄 B 或「下一项」按钮。可选择「重练全程」，清空本次记录并从追猎者重新开始。训练中可随时按 H 或使用「结束训练」按钮退出；结束后可查看记录，再返回。结束或读取训练中的存档，会回到开始的位置、生命、耐力与暑寒状态。训练前不足的生命不会被补满；主动在菜单中做出的购买、装备与成长选择保留。

首次完成全部三段获得 **硬币25、技能点1**，并留下双语旅程记录。以后可重复练习，不重复领取报酬。训练不需要新的地图、美术或主线 Boss，也不改变金发主角的身份与外观。

存档版本仍为2，旧版1/2可继续读取。仅追加可空的 `sparringReturn`，保存返回位置与生命、耐力、暑寒；旧档缺失时默认为空。训练敌人与进行中的波次不保存，读取后安全结束本次训练。保留原存档封套、校验与备份机制；异常返回数据按原位置／生命规则修复，清除不属于城镇的深渊临时状态，保留已结算收益与剧情。四个训练敌人 ID 不能恢复到正式地图或深渊。

验证入口：`tools/run_core_tests.py`、`tools/run_sparring_checks.py`、`tools/check_editor_syntax.py`，以及既有 combat、watch、signal、kitchen、archive、controller Runtime 回归。新增八组核心检查覆盖访问条件、真实命中／反击／护甲／破势、三职业通关、一次性报酬、经济隔离、世界时钟、原教学、保存／旅行与异常数据。四组 Runtime 检查操作生产输入、GUI 按钮和 SaveStore；用 `--capture-dir .starfall-checks/layout` 可生成临时离线绘制证据。

Unity 原生编译、导入、平台构建、GPU、音频、实体手柄与玩家体验均为 **NATIVE_UNVERIFIED**。离线源码编译、绘制预览与回归通过不代表已完成原生试玩。
