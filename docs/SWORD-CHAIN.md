# 短剑连段提示

持短剑时，探索和紧凑战斗 HUD 显示当前普攻连段、下一招及剩余续招时间。下一招为第三段时标出1.25倍率；真实第三段动作开始后，提示改为「重斩起手」，到接触帧后改为「重斩已释放」。倍率只说明原招式加成，反击、暴击、护甲等仍按各自规则处理。

这是招式计数，不是命中计数。原连段在成功接受普攻时推进，空挥也推进；没有足够耐力或尚不能起手的请求不会提前推进。原弓、杖的普攻也推进共享计数，换回短剑后继续按当前事实显示，不暗改武器切换和连段规则。每次接受普攻刷新1.1秒窗口，过期后的新招从第一段开始。

显示读取既有 `combo`、`comboTimer` 和 `ActorAction`。第三段已经捕获伤害后，受击可能延迟释放而续招计时继续下降；即使窗口已经结束，提示仍以当前有效的已承诺动作区分起手和释放，不把重斩误报为下一招。切换装备或打法导致旧动作失效时，不再显示它的重斩状态。技能虽也捕获连段值，但不会被误认作短剑普攻。

小条位于气候卡下、原敌人攻击提示上方，原敌人预告和其他HUD位置保留。背景会避让动态角色、投射物和危险，参与原危险补绘；鼠标攻击可穿透。它不产生点击操作，不消耗耐力，不重置计时，不改写预输入、飞行弹丸或已准备动作。菜单、暂停、训练和死亡时隐藏；真实窗口沿用原模拟时钟，不新增存档字段或重播读档前的连段。
