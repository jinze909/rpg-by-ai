# 收线反馈 / Fishing pull feedback

湖畔与河岸垂钓会短暂显示刚才一次有效收线的结果：成功、左侧、右侧；河岸整轮未收线则显示错过收线。浮标条下方的小标记保留判定时的位置，浮标仍按原速度移动。结果行显示本次成功或失误后的次数，方便对照青绿色区调整下一次收线。

- 反馈来自 Core 已接受的真实判定，不按按键或界面颜色猜测。左侧／右侧表示相对判定区的位置，适用于湖畔双向移动的浮标。
- 记录显示 1.2 秒，使用钓鱼自身的 Tick；应用暂停时保持剩余时间，不推进世界时间。河岸等候、放松阶段的按键不增加次数，也不替换上一条记录。
- 三次成功或三次失误仍按原规则结束，沿用原捕获／失败通知。原判定区、浮标速度、三阶段时长、奖励、赏金、教学与同帧单结算规则保留。
- 关闭、切换菜单、重新开钓、旅行、读档或世界重置清除记录。记录只属于当前存档对象、区域与世界代次，不新增存档字段。
- 原计数、说明、按钮位置与焦点顺序保留；反馈标记和结果行不注册任何按钮，不拦截收线或返回输入。

验证入口：`tools/run_fishing_feedback_core_checks.py`、`tools/run_fishing_feedback_checks.py`。专项覆盖实际判定、忽略输入、超时、生命周期、真实 Update／OnGUI 与双语布局；并回归原河岸教学、钓鱼输入、奖励及存档。离线界面记录和 Unity DLL 绑定编译不等于原生渲染、手柄硬件或试玩验收；原生状态为 **NATIVE_UNVERIFIED**。
