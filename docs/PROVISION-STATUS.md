# 炖汤与凉茶状态

使用炖汤或凉茶后，探索与紧凑战斗 HUD 的右侧显示仍在生效的补给及剩余秒数。炖汤标明「基础攻击 +7」：这是原基础数值的加成，之后仍经过武器、风格、每箭系数及其他倍率，并不声称每次命中固定多扣7血。凉茶标明耐力回复+6/秒和暑寒保护。远行餐、防护、战利品与教学提示继续保留各自原位置。

界面读取 `foodUntil`、`teaUntil` 与 `totalTime`，不建立第二个时钟。剩余时间向上取整显示，尚有不足一秒的有效期不会显示0秒；到期移除对应卡片。旧存档中仍合法的较长食物时长会如实显示，不截成90秒。非有限或已到期的时间不生成新卡片。

查看界面不消耗、续期、治疗或改写已准备的攻击。原规则保留：一份炖汤恢复最多55生命、补满耐力并把攻击加成刷新到90秒；一份凉茶补满耐力、清除暑寒并刷新180秒，重复使用不叠加时长。世界暂停、菜单、钓鱼、命中停顿与安全训练沿用原时钟边界；旅店和营地休息仍消耗原有世界时间。存档字段、版本、地图、碰撞、奖励与资源引用不变。

状态卡位于右侧锁定及切换目标按钮下方，避开左侧原敌人攻击提示。遇到角色、敌人、飞行弹丸或危险预告时淡化背景，并参与原危险轮廓补绘。它不接收点击，原鼠标瞄准和攻击继续穿透；中英、大字、低特效与减少动态设置保留必要信息。菜单、死亡、训练或应用暂停时隐藏世界状态卡。
