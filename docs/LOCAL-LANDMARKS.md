# 本地路标 / Local landmarks

在世界地图选择当前位置，打开右下角「本地路标」。列表沿用地图已有的探索分区，只列出该地区已探索、实际存在的居民、服务、出口、记录与机关；木材、药草和矿点不占列表位置。它不会显示尚未出现的剧情物件，也不增加任务行。

选中地点可查看地图位置、直线距离与当前步行路线状态，再明确选择「设为路标」。世界与小地图用青色标记显示自选路线，侧栏显示地点名称和到达提示。任务仍保持原来的追踪状态；清除路标立即恢复原任务导航。手柄可使用菜单焦点、确认、返回及左右肩键，原地图地区卡片与快速旅行按钮位置保持不变。

路标只负责指路，不会移动角色、交互、开门或领取奖励。走到附近后仍须手动交互。潮水、断桥、藤封与门锁都使用原来的碰撞；暂时没有路线时，界面会如实说明，原机关或潮汐变化后路径按现有导航节奏更新。关闭路线辅助也会关闭路标的世界指引。

一次保存一个地点引用，使用 `landmark_pin:<room>:<object id>` 标记；不新增 `SaveData` 字段或版本。跨地区、倒下和重新读档会保留引用，只在对应地区实际存在且已探索时生效。练习、对练和深渊保留自己的导航目标。不同存档和新冒险重建缓存，旧存档默认没有自选路标；失效、畸形或重复的路标标记只在自己的命名空间内清理，不改旧剧情标记。

## 验证范围

- 核心检查覆盖真实物件引用与模式限制、探索/剧情可见性、旧存档和新冒险、原任务与教学回退、桥梁/藤封/潮汐路径、只读查询隔离。
- Runtime 检查使用正式 `Update` / `OnGUI`、地图与手柄输入、实际步行和手动交互、正式存档封套、双语及大字界面。
- 原地图、剧情、战斗数值、人物外观、美术资源和已有 GUID 保留。界面重建预览与 Unity DLL 编译不等于原生运行验收。

原生 Unity 导入、GPU 画面、Player 构建、试玩和性能分析保持 **NATIVE_UNVERIFIED**，等待持证 Editor 验证。
