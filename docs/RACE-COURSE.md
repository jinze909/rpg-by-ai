# 沙舟风旗竞速：路线预览与明确退出

沙海原有「先看看路线」选项只关闭对话，现在会打开可操作的赛道页。原沙舟、五面风旗、移动与闪避、竞速加速、耐力恢复、抗热及报酬沿用现有系统。

## 操作

1. 在玻璃沙海靠近沙舟，按 E／手柄 B 交谈。第一项「出发！」仍直接开始比赛；第二项「先看看路线」显示真实地形、五旗编号、当前位置、最快纪录及奖励领取状态，不启动计时。新增「稍后再来」可直接离开。
2. 在预览页选择「出发！」才开始新的一轮。五旗顺序仍为 `(8,18) → (8,5) → (23,5) → (30,18) → (14,18)`。地图不提供自动驾驶，路线与闪避由玩家控制。
3. 比赛中按 Esc／START，在暂停菜单选择「沙舟路线与退出」。页面暂停世界与竞速计时，标出已过风旗与当前目标。「继续本轮」或 Esc／B 返回世界，保留同轮时间与进度。
4. 「结束本轮…」先打开确认页，默认键盘／手柄焦点在「继续本轮」。取消确认或 Esc／B 会留在暂停的赛道页；只有「确认结束本轮」结束比赛。结束不发奖、不收费、不传送，重新出发需要回到沙舟。
5. 页面沿用鼠标、Tab／方向键／摇杆、Enter／A 与 Esc／B 操作。未比赛时的其他暂停入口及试装训练场控制保留。

## 时间、奖励与存档

- 五旗依次接触，30秒整可以完成，超过30秒先判结束，再处理终点；修复旧版在30.01秒接触第五旗仍能发奖的顺序错误。
- 首次完成仍为25硬币、3碎片；不超过16秒的风行徽章仍额外给5碎片、1技能点，均只发一次。再次完成可改善最快纪录，不重复发奖。
- 正在比赛时再次选择原「出发！」不会静默清空同轮时间与进度。新比赛必须从真实沙舟附近开始；不新增敌人附近禁止出发的条件。
- 查看、继续与取消不治疗、不扣物资、不重置战斗冷却。世界恢复后仍遵守原战斗、地形与气候规则。
- 最快纪录及已领报酬继续保存在原字段中。比赛和预览都是临时状态，读档、旅行或新游戏后清除，不新增存档字段；旧 v1／v2 存档可继续使用。
- 页面绑定当前存档、世界代数、沙舟及比赛状态。更换存档、地图或临时比赛数据后，旧页不能出发或结束新的一轮。

## 验证入口与边界

- `python3 tools/run_race_course_core_checks.py`：四组核心行为检查，覆盖真实对话、出发与拒绝条件、暂停、确认、奖励时限、三职业五旗实走、重复奖励和旧存档。
- `python3 tools/run_race_course_checks.py`：四组离线 Runtime 检查，调用生产 Update／OnGUI，覆盖 E／数字选择、键盘与手柄、鼠标、暂停与确认、三职业实际移动、30秒边界、旧档校验及双语布局。`--capture-dir` 可导出实际 OnGUI 绘制命令；`--baseline-ref` 可隔离编译旧提交做语义负向验证。
- 新 Core 检查接入完整 Core 回归和 Unity NUnit 包装；Runtime 检查接入 GitHub Actions。相关厨房、训练场控制、景物检查及 Unity 2022.3.53f1 DLL 编译用于验证接线兼容性。

离线绘制命令预览与 DLL 编译不等于 Unity Editor 导入、GPU 字体渲染、Player 构建或真实手柄试玩；原生验收仍为 **NATIVE_UNVERIFIED**。
