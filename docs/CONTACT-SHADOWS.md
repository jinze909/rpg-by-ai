# 角色接地阴影

本次 Visual Renaissance 单元从 `95eaa62` 接续。美术规范要求脚下透明椭圆落影，但原生产路径为主角、普通怪物、Boss、居民和同伴绘制硬矩形。实际怪物/Boss 图格检查未发现可直接复用的统一烘焙落影，因此保留原画格，仅替换原脚下阴影。

## 实现

`FrontierContactShadows.cs` 生成一张64×16 RGBA32、Point/Clamp、无 mipmap 的共享遮罩，像素约4 KiB。五档透明度向边缘递减，四角透明，中心对称。Awake 提前生成；绘制期只查询缓存，不创建纹理或读取源图像素。所有权、销毁和显式再次准备均沿用 PixelArt 生命周期，不销毁借用的 Resources 图集或遮罩。

原脚底相对范围、色值与最高不透明度保持：

| 路径 | 宽×高 | 脚底上偏移 | Alpha |
| --- | --- | --- | --- |
| 主角三种装备 | 34×7 | -3 | .38 |
| 三类普通怪物 | 42.24×7 / 重甲46.64×7 | -3 | .35 |
| 八地 Boss | 105.6×7 / 潮壳116.16×7 | -3 | .35 |
| 居民/同伴缺图回退 | 26×5 | -2 | .32 |
| 三名同伴 | 28×6 | -3 | .32 |
| 主角旧图回退 | 30×7 | -1 | .30 |

阴影仍在原排序位置、角色之前绘制，HUD 前景轮廓不重复绘制地面阴影。最低特效、减少动态和暂停保留相同的接地信息。原倒地敌人/Boss 没有新增落影；其姿态、朝向、淡出和生命周期保留。

主角缺图回退提前选择自己的呈现路径，避免先画正式主角阴影/沙舟，再叠画旧图阴影/沙舟。正常竞速的船与画格不变；回退只保留自己的那一条船。没有修改主角身份、资源、动画帧、武器接触/闪避时机、剧情、地图、碰撞、存档字段或玩法数值。

## 定向证据

`tools/run_contact_shadow_checks.py` 使用生产 Core/Runtime 与离线 Unity 声明，默认执行四组检查；CI 新增该脚本并保留全部旧步骤。重启后有截图和无截图运行均为 **4/4**。`--baseline-ref 95eaa62` 从只读 Git 归档编译旧生产源码，编译成功后为 **0/4**，不是通过编译失败制造红灯。

- 对称、连通、透明角、分档渐变与椭圆范围；Awake 预热、冷查询不生成、反复复用、借用/生成所有权、销毁和显式重建。
- 440组画格/朝向/动作/受击/倒地/同伴/居民/回退记录，去除阴影后与不可变基线的完整纹理、UV、密度、锚点、颜色、矩阵和顺序摘要一致；另补三职业正常竞速及回退的单船/单阴影断言。
- 实际 Layout/Repaint、HUD 重叠轮廓、低高特效、暂停及减少动态；完整 GameCore、存档/备份文件、GUI 状态只读。
- 真实普攻接触、三职业闪避末步、敌弹受击/死亡、敌人倒地，以及有/无绘制的重击范围内/范围外/闪避六种结算；没有调整战斗时机或数值。

相关回归已通过：主角 A–E（含六种故障注入）、威胁轮廓4/4、地图3/3、水岸5/5；既有角色注册156/84/99组合及三组 HUD/动作/排序检查。五阶段真实 Unity DLL 编译通过。276组元数据和7项检查器自测通过；477个受保护基线文件（含275份旧元数据、87项 LFS 引用）保持字节或 OID 一致。

24对离线生产 OnGUI 画面覆盖八地 Boss、三类普通怪、三职业、同伴、HUD、暂停和回退，48张近似预览无估算文字溢出；代表场景和4倍最近邻脚部对照已人工复看。日志/图像仅存于 ignored 的 `.starfall-checks/contact-*`、`layout/qa-contact-*`、`qa-previews/qa-contact-*`。

**NATIVE_UNVERIFIED**：没有执行持证 Editor 导入、Frontier 原生运行、GPU 采样、Player 构建或试玩。真实 DLL 编译与离线纹理合成不代表这些验收通过。原生验证仍按已记录的许可证条件延期；后续需复看不同 GUI 缩放下的椭圆边缘、主角 RT 合成顺序及真实帧时。
