# 战斗浮字分层

基线 `f3bca12`；恢复点 `refs/codex/checkpoints/combat-text-baseline-f3bca12`。

一次重甲命中原本可以在相同坐标同时产生“正面护甲”“破势”和伤害数字，三个完整文本却使用同一个矩形与上升轨迹。星火范围攻击也会让邻近目标的结果互相盖住。本次只改变这些现有浮字的排布，不新增、合并或省略战斗事件。

每条存活文字首次出现时取得固定偏移，避免与已有文字重叠，并为原有22像素上升及1像素阴影留出完整范围。旧文字消失后，其他文字不回填空位；镜头移动仍跟随原事件的世界坐标。单条文字保持原120×32矩形、19字号（大字20）、暗影后金色、原文本和上升轨迹。暴击前缀、`+HP`、护甲、破势等原文本均保留。

只有发生碰撞的新文字才换位，优先选择画布内最近的空位并避开当前 HUD 区域。原本完全在画面外的新文字保持裁剪，不从远处拉入画面。保留原单条文字与 HUD 的叠放规则，不新增覆盖菜单或危险预告的前景文字层。为避免跳动，固定位置不会随之后出现的 HUD 重新排布；极端画布饱和时仍保留全部原消息并向上分离，可能超出视野，不把它们合并成一个统计数。

位置记录只引用当前存活浮字，复用列表存储；过期、移除、世界代次切换时清理，退出测试场和销毁时释放引用。没有新增存档字段、资源纹理、伤害规则、治疗规则或计时器。Core 的实际接触与生命周期继续决定生成和移除，暂停也继续使用原时钟。低特效、减少动态和大字模式保留同一套关键信息。

## 主角承伤反馈

主角在正式 `Hurt` 接触中实际失去生命后，产生独立的浅红 `damageTaken` 浮字；敌人的伤害、暴击、破势及原 `+HP` 文字保持金色。显示减号和最多两位小数，使用固定小数点；实际损失小于0.01时标为 `-<0.01`。计算读取原扣血前后差值，包含难度、护盾、天赋、祝福、遗物与料理减伤，致死只显示原本剩余生命，不改变任何伤害公式。

无敌时间、完美闪避、教学、切磋、试装训练场没有真实扣血便不产生承伤数字。原受击动作、闪红和音效保留，环境及敌人命中共用同一接触入口。

新数字共用现有固定排布、22像素上升与0.7秒生命周期，最后0.2秒淡出；首次排布还会避开 HUD。镜头后来将它带到 HUD 下方时，仅重复这类新文字到 HUD 上方，包含致死受击，原文字层级保持不变。低特效与减少动态保留提示，暂停沿用模拟时钟。过期、切换地图、读档和退出预览沿用现有效果与排布清理；不增加存档字段或资源。

## 实际治疗反馈

五种既有战斗回血现在显示实际收到的绿色 `healthGain` 数字：炖汤最多55、回潮瓶闪避3、薪火徽记战技8、米拉自动治疗6加羁绊、米拉指令18加羁绊×3。只读取各次回血前后的生命差值，原治疗公式、消耗、耐力、护盾、音效与冷却不变。米拉自动治疗的泛称 `+HP` 改为实际数额；指令保留原治疗环及实收回执，其他金色文字与浅红承伤数字保留原表现。

生命已满、治疗溢出或输入被拒绝时，只显示实际正差值；完全没有恢复便不生成绿色数字。炖汤通知也改报实收生命，满血使用仍按原规则消耗一份、恢复全部耐力并获得90秒攻击增益，不再夸大为固定55生命。

治疗数字跟随原事务发生：炖汤使用、遗物战技成功支付、遗物闪避真正开始、米拉自动治疗0.16秒接触及指令0.20秒接触。缓冲输入和治疗准备阶段不会提前回血或出现数字，米拉在准备期间遇到其他治疗回满时也不再显示虚假恢复。数字使用固定小数点、最多两位小数；极小正值显示 `+<0.01`。

绿色文字共用现有0.7秒生命周期、排布、上升、最后0.2秒淡出与 HUD 避让，低特效保留同样信息。暂停与菜单沿用模拟时钟，换图、读档及退出预览清理瞬态效果。休息、升级、深渊下层补给和死亡恢复等其他上下文保持原样。本轮没有新存档字段、原美术或场景改动。
