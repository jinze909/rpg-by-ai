# 旧路复试 · Warden reprise

完成原「旧路守望」后，在密林第三处旧灯按 E，保留的结局选项之后新增「旧路复试」。返乡侦察员处也可查看说明，正式开始和手动结束都需要回到第三处旧灯。准备动作、闪避或受击尚未结束时，先完成动作再选择开始。

复试重现同一位300生命守望者的完整三招：锁定直线冲刺、留有中间空隙的双印、正面中路开放的四发散射。起手时间、地形碰撞、受击、破势、恢复窗口与弹道规则沿用原战斗。可以使用当前三职业、武器、打法、战技、遗物、同伴和目标锁定比较新配置。

这是原森林中的自愿实战，正常承伤和消耗物资，世界时间照常推进；开始、结束或重新尝试不会回复生命／耐力，也不会退还消耗或重置冷却。复试守望者不产出重复的技能点、碎片、经验、硬币、材料、熟练度或悬赏进度。其他森林敌人和它们的正常战斗、报酬保留。原完成旗标、结局、首胜报酬和主线 Boss 进度保持原样。

面板记录本次用时、玩家自身对守望者造成的实际生命损失、有效接触、破势与受击次数。超出剩余生命的伤害不计入，同伴伤害不混入玩家伤害；同伴可以正常协助获胜。受击计数包括本次复试期间实际造成生命损失的森林攻击。计时只跟随有效世界模拟步骤，菜单和命中停顿冻结，旧档总时长很大也不影响本轮精度。它是比较记录，不是排行榜，难度、装备和补给仍由原系统控制。

获胜后保留结果，手动回灯旁可以再试；未获胜也可在灯旁选择结束。当前和前一次结果只在本地区会话保留。旅行、死亡、读档、新冒险和训练重置会结束会话；读档保留普通森林敌人的断点、原任务和资源，不恢复未结束的复试，也不凭空获胜或发奖。原死亡回镇及10硬币损失规则保留。

开始和结束会清理未落地的玩家／同伴攻击、旧寒星领域和守望者弹体，避免旧一轮攻击进入新记录；普通森林敌人和它们的敌方弹体不会被清场。结果面板只读，不拦截瞄准与攻击，参与原危险圈淡化与轮廓提示。首胜与复试的倒地身影按敌人实例区分结算提示，快速再试或结束不会把首胜报酬改写成复试报酬。探索布局与同伴指令提示保留分离空间。低特效和减少动态仍显示同样的记录。

复试只持有当前敌人、存档实例与世界代次的会话引用，复用原守望者保留身份73000；不新增 SaveData 字段、版本、地图、场景、美术或旧 GUID。既有已完成守望任务的恢复规则会排除复试敌人，旧 v1/v2 档继续使用原校验和与备份路径。

验证入口为 `tools/run_signal_reprise_core_checks.py`、`tools/run_signal_reprise_checks.py`、原核心与守望／战斗／存档相关回归。离线生产 Update、OnGUI、SaveStore 与实际 Unity DLL 编译各自只证明对应层面。Unity Editor 原生导入、Frontier 场景、GPU、实体手柄、Player 构建和实际试玩保持 **NATIVE_UNVERIFIED**。
