# 第一封回信 / Lune's first reply

完成遗潮档案、交回雾港调查报告后，余烬镇的露恩新增一项可选委托。原来的远岸来信、旅行、建设与委托簿入口保留。

1. 在露恩处接信，到公会请莉雅核对三份实际找回的原册。
2. 在雾港救下孩子和摆渡人，让他们亲自核对各自的那一页。孩子记得照顾过自己的人；摆渡人核对高地回村的支路。两人的回话都不证明失踪者已经归来。
3. 救下灯匠，修好南侧第三座灯线。在灯旁开始交接：准备 **1.25 秒**，灯亮后有 **2 秒**按 E／手柄 B 确认。
4. 把回执带回露恩。首次交付获得 **凉茶 ×2、摆渡盟声望 +1**；重读不会再次发奖。

档案的“家人先核对”与“公会公开记录”选择继续影响对话，原册与旧奖励不变。灯光只确认回信收到，不公开名字，也不许诺失踪者归来。

## 操作与失败处理

准备阶段提前交互只提示等候，不会自动交付。错过时间、离灯超过 2.5 格、附近出现敌人或切换世界会结束这次交接；可免费重试。实际确认仍须靠近到正常交互范围，有通路且附近安全。菜单、应用暂停和命中停顿沿用游戏时钟，不消耗交接时间。

计时条来自实际任务状态，低特效、减少动态与大字设置保留同样的信息。HUD 使用当前键鼠／手柄提示，只读且不吞掉世界鼠标输入，沿用危险重绘规则。

任务手帐每页保留 19 行。旧任务顺序、行坐标与追踪／查看地图按钮保持原样；第二页可选择、追踪新任务。分页支持鼠标、键盘焦点和手柄确认。
