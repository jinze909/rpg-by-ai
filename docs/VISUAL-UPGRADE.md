# 画面、界面与引导重制

本次在《星陨边境：远岸来信》的完整项目上升级，继续保留九个地区、三职业、两条剧情线、三位同伴、六件遗物、城镇建设与六层深渊。

此文记录上一阶段的画面与界面基础重制，其中32像素地形和前三格职业肖像已被替换。当前统一主角、敌人、Boss、地图与动作的实现见 [VISUAL-COMBAT-UPGRADE.md](VISUAL-COMBAT-UPGRADE.md)。实战教学与玩法打磨见 [RPG-POLISH.md](RPG-POLISH.md)，当前验收数量以 [QA-REPORT.json](QA-REPORT.json) 为准。

视觉与界面方向参考《Sea of Stars》这类现代像素 RPG：清晰的人物肖像、区域色彩、光源氛围、可读的战斗预告和统一的信息层级。素材与代码为本项目的新实现。

## 画面

- 原创暮色海湾标题插画、八人肖像图集。职业选择、HUD、对话与同伴界面使用同一套肖像。
- 32×32 地形纹理：草丛、花点、石块、铺地、潮滩、沙纹、积雪、水波与岸边泡沫。
- 大树、两类房屋、遗迹石拱、灯柱、棕榈、雪松与灯塔使用新的透明像素道具图集。其他场景道具加入方向明暗与纹理，保持既有地图的通行规则。
- 白昼与夜晚、沙海暖色、高原冷色、深渊暗色的氛围；灯具、晶体和火盆的柔光。
- 攻击弧线、飞行物拖尾、破势显示、伤害数字描边、受击震动和入区提示。
- 环境特效有三档；减少动态效果会停用晃动、摇树、浮动目标、水面动态和雪粒。

目前仍使用原项目的 Built-In / IMGUI 渲染。光晕和色调由运行时代码绘制；本次没有切换 URP 或实现物理光照。新增材质图形缓存后复用。

## 全套界面

标题、HUD、背包、成长、遗物、同伴、城镇建设、公会悬赏、手帐、地图、对话、钓鱼与设置统一重做。采用深蓝底色、象牙白文字、金色目标、青色状态；菜单共享左侧导航、头部与返回操作。

背包支持选中物品查看用途和来源；技能栏显示消耗品数量、可用状态与冷却；遗物明确显示代价；同伴显示肖像与羁绊；地图可检查锁定地区的解锁条件。点击 HUD 或菜单按钮不会同时触发攻击。

对话按内容自动分页，读到最后一页才显示选择。空格 / Enter 或按钮继续阅读，数字 1–5 或鼠标选择。长记录不再挤在一个文本框里。

## 教学与任务指引

新游戏的八步教学分别记录：实际行走、互动、追踪任务、攻击、闪避、职业技能、查看背包、进入密林。动作可以提前完成；提示会切到下一项未完成的动作。设置里可以跳过、关闭或重新开始，已有存档不会被强制重新教学。

F1 打开十二类冒险指南：操作、战斗、任务、补给、成长、同伴、建设与悬赏、石碑、潮汐、光路、寒意、深渊。完整中英文内容随时可读。

手帐提供主线、远岸、三项镇民委托、三项同伴故事和当前悬赏的步骤、奖励、下一步与目标地图。接取远岸调查或悬赏会自动追踪；收够材料后目标切到交付地点，交回星核后切到下一章。

路线按实际地图碰撞寻路，终点落在可互动范围。路线不会穿过房屋、墙、关闭的屏障或高水位潮滩。潮水阻路时给出等待退潮或开启闸门的提示。近战危险时收起地面路线；目标标记仍可见。跨区域目标先指向出口；屏幕外有方向标记；小地图记录已探索扇区。

## 覆盖升级

1. 关闭 Unity，先备份你现在能正常运行的项目。
2. 将包内 `Assets`、`Packages` 的内容覆盖到该项目同名文件夹。
3. 同步包内 `ProjectSettings`；本轮也更新 `ProjectVersion.txt`，只保留 `m_EditorVersion: 2022.3.53f1` 一行，使用国际版 Unity 2022.3.53f1。其他已能运行的国际版 2022.3 LTS 补丁号，填写该版本的真实编号。
4. 打开原来的项目，等导入结束；双击 `Assets/Scenes/Frontier.unity` 后 Play，也可用 `Starfall → Play Adventure`。
5. 旧存档沿用 `starfall-v1.json` 与原产品名称；新增偏好和探索记录会自动初始化。无需为了升级开始新游戏。

## 验证范围

此阶段通过十五组实际 C# 核心回归检查。当前扩展至二十八组，包括三职业主线、全部远岸方案与协定、六层深渊、旧存档、教学、任务切换、地图避障、动作接触、死亡恢复和特效来源，详见最新验收记录。

生产运行时代码用离线桩编译并记录界面；检查中英文、两档文字大小、所有教学与指南、九类任务、物品详情、居民对话和记录分页。另验证数字选择不会跳过未读对话，Enter 可以翻页并在最后选择。

`python3 tools/run_core_tests.py` 与 `python3 tools/run_layout_checks.py` 可复现。需要 Mono、Python、Pillow；字形覆盖检查使用 FontTools。

`docs/previews` 是生产代码的离线布局预览；`docs/QA-REPORT.json` 给出检查数量。字体度量和显示效果以 Unity 实际运行结果为准。本环境没有 Unity Editor / Player，未进行 Unity 原生编译、音频试听或平台构建；不能将离线检查当作实际 Unity 试玩。
