# 湖畔鱼篓与存档容量

老潮的原湖畔钓鱼入口保留原剧情、按钮次序和交鱼委托。对话另列鱼篓当前数量／9999，以及此刻成功可获得的硬币（0 至 4，硬币上限 999999）。鱼篓已满时不能开始新一轮，可先交鱼或制作炖汤腾出空间；对话仍可继续，其他原选项不受影响。

满容量使开钓不可用时，默认 Enter／手柄 A 安全选择「再见」，不会转而自动交付三条鱼。仍可明确选择原交鱼按钮；点击或按原编号选择不可用的开钓项不会关闭对话。

- 开钓与第三次成功结算均检查鱼的空间；旧按钮或中途变化不能写入第 10000 条鱼。空间不足的结算不发鱼、不发硬币、不增加钓鱼悬赏，也不显示成功重试。
- 普通成功仍需要三次有效收线，获得一条银鳍鱼和 4 硬币，不消耗鱼饵；原失误、取消、时序、老潮委托与河岸记录保留。
- 接近硬币上限时，湖畔只增加上限内的硬币，满硬币仍可钓鱼，对话会准确显示硬币 +0。从合法容量内开始的新奖励，写盘前后和重新加载后的鱼、硬币数量一致。若其他旧奖励路径已使当前余额超限，钓鱼不会再增加硬币，也不截断既有余额；旧档原加载规则保持。
- 没有新增存档字段、待领取鱼获或迁移。既有旧档的载入规则保持；鱼获上限保护不改变河岸成熟的结算与记录规则。
