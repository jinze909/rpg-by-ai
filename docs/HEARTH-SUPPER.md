# 炉火共餐 / A place at the hearth

完成杏、老潮、诺尔三份原镇民委托后，阿茴的原菜单末尾出现「炉火共餐」。这是一条有限、可保存的生活故事：先前的药品、给孩子的鱼汤和修好的水泵，让居民有余力一起准备晚饭。原委托交付与报酬不重播、不替换，也不要求再次交材料。

## 玩家流程

1. 在镇中或旅店与阿茴交谈，自愿接下共餐；任务手帐新增最后一项，原十八条任务索引保留。
2. 在镇中分别与杏、老潮、诺尔确认准备，顺序不限。他们留在原来的药田、湖边和铁匠位置，种植、钓鱼、买种子、强化和制作选项保留原编号。
3. 到**炉火旅店内部**找阿茴备餐。镇外厨师与野外营地不能代替这一步。
4. 给现有两张桌旁的三处位置送汤。三个汤碗标识由金色转为薄荷色；每处有独立故事，顺序不限。没有时限，没有消耗库存炖汤，也不移动或复制原居民。
5. 回旅店阿茴身边，共餐并领取一次性的炖汤 2、凉茶 1。不会增加技能点、经验、硬币、关系、永久属性，不替换已有远行餐或提前消耗其时间。

桌边故事和阿茴的共餐结束对话可重复阅读，不重复发奖。失踪巡路队仍未被宣布归来；共餐是给仍在等候的人留一份热饭。

## 集成与兼容

- 仅使用 `supper_accept`、三份 `supper_prep_*`、`supper_cooked`、三份 `supper_served_*`、`supper_complete` 持久标记。没有增加 SaveData 字段或更改存档版本。
- 每步再次校验实际地点、互动距离、阶段、生命、练习与模式。复制 ID 的伪造桌边对象不能交互；旧菜单回调不能远程备餐、送汤或领取奖励。
- 任意阶段可离开旅店、暂停或读档；不自动推进、不自动发奖。旧存档不会凭空拥有新的完成进度。
- Campaign 只在原旅店对象列表末尾追加三个非阻挡互动点；原地图、地形、装饰、对象顺序和坐标全部保留。碗使用已有图标，不引入 NPC、美术、字体或场景资源。
- 手帐第十九行使用原页脚上方的空位，并保持在临时提示框之上；原十八行的尺寸和点击区域保留；正常/大字、中文/英文均有真实 OnGUI 检查。
