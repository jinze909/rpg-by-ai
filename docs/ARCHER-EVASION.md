# 射手贴墙脱困

普通射手在看见近处玩家、准备下一次射击时，仍优先按原规则直线后撤。如果这一步被墙、岸缘或其他现有碰撞挡住，才尝试沿墙两侧的小步，选择能增加与玩家距离的一侧；角落中会继续检查侧向落脚，两侧都不能安全拉开距离时保留原来的后撤结果。相同进展时使用固定方向，不随机跳动。

所有候选位置都经过原来的脚底碰撞扫掠，每帧仍只使用原 `1.6 × dt` 的后撤距离预算。不会穿墙、穿水、越过封印或封闭竞技场，也不会通过向玩家挤近来离开角落。普通追踪、视野和攻击距离不变。

脱困只发生在原本允许后撤的空闲阶段。射手一旦拉弓，位置与朝向继续遵守原攻击承诺；原 `.65` 秒预告、箭速、伤害、恢复、命中、破势和受控规则保留。Boss、基础木桩教学和冻结的试装靶不使用新侧移；战术切磋中的射手继续沿用正式普通敌人规则。

继续使用现有后撤步态与朝向。没有新增地图、素材、输入、奖励或存档字段；旧存档中的敌人位置仍由原敌人快照保存和恢复。

`tools/run_archer_evasion_core_checks.py` 检查实际地图的贴墙脱困、角落拒绝、原直线后撤与攻击承诺、生命周期和旧存档。`tools/run_archer_evasion_checks.py` 通过生产 Update／OnGUI 检查移动、攻击、动画选帧与 SaveStore 接线。

原生 Editor、PlayMode、GPU、手柄与玩家手感验收仍为 **NATIVE_UNVERIFIED**；离线检查和 Unity DLL 编译不能替代原生试玩。
