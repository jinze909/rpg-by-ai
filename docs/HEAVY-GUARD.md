# 重甲的正面护甲提示

基线 `efdf687`；恢复点 `refs/codex/checkpoints/heavy-guard-baseline-efdf687`。

原重甲只有命中后的“正面护甲”浮字，战术提示又出现在护甲已关闭的蓄力阶段。现在存活的普通重甲在护甲生效时显示静态、开口朝后的灰蓝盾弧，随实际朝向转动；野外与艾妲的真实对练都可在接触前读懂防御方向。冒险指南保留原有教学并解释新提示。

原 Hit 判定抽取为共用的只读资格与正面接触谓词：非 Boss、kind2、state0、stun≤0；非技巧攻击从严格点积大于 `.45` 的方向命中，仍只造成原40%伤害。没有改变阈值、倍率、伤害、攻击/冷却时机或 AI。受击与释放动画本来不会关闭护甲，提示也保留；蓄力、受控、死亡、菜单、安全木桩和清场对练回顾不显示。其他敌人和 Boss 不获得普通重甲护甲。

盾弧使用原白纹理和暗底亮边线段，半角与实际 `.45` 判定对应。半径0.8格仅为小型护甲标记，不是攻击范围。每个可见合格重甲提交24段暗衬与24段亮边；保守范围同时用于 HUD 渐隐和一次前景补绘。低特效、减少动态不删关键提示；没有新增纹理、计时器或缓存。原身体、血条、动作、主角与全部美术保持原样。
