# 地域环境微动

Visual Renaissance 单元，接续 `67f55a5`。生产 OnGUI 审查确认：所有地图都叠着同一组18枚金色光点，霜钟高原另外叠28枚白色雪点。沙海、矿场与雪原缺少独立的空气质感。

## 玩家可见表现

- 霜钟高原：只呈现冷色飘雪。远层较小、较淡、较慢，近层稍快；少量断开的像素簇代替单一大方块。
- 玻璃沙海：暖灰沙尘横向掠过，细碎、稀疏，不绘制大片沙幕。
- 赤铁矿场：低亮矿尘缓慢上浮，保留原地形、灯火与环境色层。
- 其他地区保留原18枚萤光的坐标、颜色、速度与绘制顺序。

两个深度层随镜头分别以地表15%和35%的位移移动。位置直接由稳定种子、现有呈现时钟与世界投影计算，没有粒子生成、累积、寿命列表或新存档字段。循环在屏幕外24逻辑像素的缓冲区发生，并在缓冲区淡出；新图形使用整数逻辑像素。

低特效保留同一批粒子的前半组，调档不会给保留下来的粒子另选位置。最低特效与减少动态均关闭环境粒子，沿用原有设置约定。雪原旧版两组共46次绘制由完整的新雪层替换；没有删减地图、天气玩法或探索信息。单次绘制矩形至多5×2逻辑像素、最高 alpha .4，战斗危险轮廓与 HUD 在其后绘制。

沿用原呈现时钟：菜单背景仍缓慢移动；应用暂停与冻结视觉审查停止时钟。没有调整战斗 hit stop、Core 世界时钟、寒意、暑热、火盆、风道预警或环境伤害。旅行与手动改变镜头可改变粒子分布，没有加入跨地图时间插值。
