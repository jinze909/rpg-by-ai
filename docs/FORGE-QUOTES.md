# 诺尔的工坊报价

在诺尔附近按 E，原来的前三个选项仍是强化装备、猎弓、星火杖。已有武器显示「免费」装备，直接沿用原换装行为；不再把已有武器标成需再次制作。装备达到5阶，或当前材料不够时，对应交易按钮不可用，选择不会扣料，也不会把对话关掉。

菜单末尾的「查看工坊报价」使用原对话与翻页控制。报价页显示库存、每种配方的材料差额，以及下次强化的等级、装备攻击加成、最大生命和当前生命变化。原价格保持：

- 强化一级：木材3、星晶2、零件2，上限5阶。
- 制作猎弓：木材4、零件2；拥有后免费装备。
- 制作星火杖：星晶4、零件3；拥有后免费装备。

装备攻击加成是每阶增加4的基础项，打法、熟练度与战斗状态仍按原公式另算。强化仍增加20最大生命并回满生命；报价只是查看，不会治疗。满级报价显示原生命，不再显示一次不存在的强化收益。

交易在执行前重读实际库存，报价不会成为支付凭证。成功制作或强化仍返回世界；报价页可返回诺尔原对话。原来的零件委托、晚餐任务、对话剧情和选项顺序保留。

没有新增存档字段、版本或永久报价记录。v1/v2沿用原迁移，已有装备方案、职业、天赋、熟练度与任务保持。查看报价不取消已准备攻击或改变已释放弹道；实际换装继续遵守原动作取消规则。
