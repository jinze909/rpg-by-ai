# 阿茴的远行厨房 · Ari's Road Kitchen

药田、湖边与野外采集现在能支持出发前的战术选择。余烬镇或薪火旅店的阿茴保留原炖汤、购买与凉茶服务，新增「远行厨房」选项。按 E 交谈，读完对话后按 **6** 进入；原先 1–5 的选项与顺序保留。鼠标和现有手柄菜单焦点也可选择。

三种远行餐各持续 **180 秒**，一次只保留一份。菜单显示材料库存、当前餐与剩余时间；选择配方会立即扣料并启用效果，不产出新的背包物品。

| 远行餐 | 材料 | 效果 |
| --- | --- | --- |
| 药草鱼餐 · Moonherb fish | 月光草2、银鳍鱼1 | 耐力每秒额外回复3 |
| 炉火鱼汤 · Hearth broth | 木材1、银鳍鱼1 | 战斗伤害减少10%，暑寒伤害不变 |
| 星路清餐 · Starpath greens | 月光草2、星晶1 | 普通步行速度增加0.3，闪避与沙海竞速不变 |

炉火鱼汤覆盖近身攻击、射弹、范围攻击及裂隙风暴，不提供暑寒免疫；原凉茶仍负责环境保护。星路清餐不增加冲刺距离、Q 位移或竞速速度。药草鱼餐可与凉茶的耐力回复同时生效。

再次制作同一餐会支付完整材料并更新到180秒；制作另一餐会支付新配方、替换旧效果。材料不足、离开厨房、训练或死亡状态都不会扣料或改变现有餐。备餐本身不回复生命或立即补满耐力；原炖汤的治疗、攻击加成、同伴赠礼以及凉茶功能全部保留。

建成远行驿站后，靠近远岸地区的安全营火也可进入厨房。敌人仍在现有安全范围内时不能备餐；营地休整与每日凉茶补给沿用原规则。三种配方首次制作会留下旅程记录，无额外领奖或重复奖励。

HUD 显示餐名、倒计时和效果，背包在物品格与武器比较之间显示同样的信息。暂停、对话和其他菜单冻结世界时钟；旅店休息推进45秒、营地休整推进20秒，因此会消耗相应的餐效时间。旅行、死亡回镇和读取保留余下效果；新旅程从无餐状态开始。

存档仍为 v1/v2，只追加零默认的 `mealKind`、`mealUntil`，不改既有字段或八项物品数组。旧档缺失这两项时没有增益；读取会清理无效种类、非有限时间与已到期状态，并限制最长剩余180秒。材料、故事、职业、原地图与全部现有 GUID 保留；新增界面只使用原炖汤图标和现有字体。

验证入口：`tools/run_core_tests.py`、`tools/run_kitchen_checks.py`、既有 combat / watch / signal Runtime 回归，以及 `tools/check_editor_syntax.py`。厨房 Runtime 工具操作生产 E、数字6、分页配方、F/T、HUD、背包、营地与 SaveStore，可用 `--capture-dir .starfall-checks/layout` 留下临时绘制证据。实际位移、耐力、伤害、竞速、旧档和到期边界另有核心检查。

Unity 原生编译、GPU、音频、手柄与玩家体验仍为 **NATIVE_UNVERIFIED**。离线绘制记录和生产源码回归不等同于原生试玩或平台构建。
