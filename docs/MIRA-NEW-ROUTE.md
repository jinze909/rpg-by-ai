# 米拉的新航线 · Mira's new route

米拉交还名册后开始写的新航线，现在可以亲自陪她走完。旧路河岸的巡查与两份记录成为同伴故事的后续：确认两段道路、应对沿路敌人，再决定营地路图与家人路图的交付顺序。失踪巡路队的命运没有被改写，原记录始终保留。

## 开始与同行

取得第一枚星核、完成旧路河岸巡查，并完成米拉的个人名册故事、解锁她后，到雾港 `(15,16)` 找实际的米拉。原赠礼、邀请同行、告别三个选项保留；第四项 **米拉的新航线** 提供说明与接取。

接取只追踪新任务，不自动替换当前同伴。在 C 同伴栏邀请米拉，再从密林入口或世界地图返回旧路河岸。她沿用原寻路、治疗／护盾与 Z 战术指令，不传送追赶，也没有新增护送生命条。到达交互点时，等她走到主角附近再确认。

## 复走调查出的道路

| 顺序 | 地点与操作 |
| --- | --- |
| 河心旧灯 `(39,29)` | E 交谈，选择追加的第三项“与米拉检查航路”。清理两名敌人，再回旧灯按 E，选择“与米拉记下这段路” |
| 东岸旧灯 `(61,12)` | 完成河心记录后，同样手动开始第二场遭遇、清理两名敌人并记录路线 |
| 河岸旧记录 `(24,10)`、旧灯名册 `(65,18)` | E 找回两份原有记录；已经读过的记录直接计入，不要求重复发现 |
| 河岸营地 `(11,38)` | 米拉在附近、周围安全时，E 交谈并选择第七项“米拉的新航线”，完成交付 |

两场遭遇使用正常追猎者、射手与重甲规则，合计四名敌人。攻击、战技、闪避、米拉支援、掉落、经验、熟练度和悬赏进度均沿用正式系统。旧七名守卫与隐藏补给保留；尚未处理的旧敌人仍需正常应对。南北常通路线、可修浮桥和藤封小路都保留，新故事不强迫修桥。

Tab 手帐在原十四项任务后追加“米拉的新航线”。金色路线与地图先指向未完成的旧灯，再指向尚未发现的记录，最后指向营地。需要米拉同行的提示不会把另一位同伴当作见证者。

## 营地抉择与回话

- **留下公用路图**：营地先有可供来往者使用的路线，名字交给家人。
- **先给家人送路图**：米拉将带名字的路图交给家人，营地保留不带名字的路线。

两种选择均首次获得 **硬币30、碎片3、米拉羁绊+1（上限5）**。原调查、旧记录和正常战斗各自的奖励保留，重复阅读或切换选择不能重复领取。营地可重读已选结果；三核交付后，莉雅原有巡路队回信也会提到这份新路图，不增加交核报酬或改写结局条件。

## 保存与既有内容

接取、手动开始的遭遇、四名敌人的击败、两次路线确认和最终选择使用独立永久 flag。原地读档保留有效存活敌人的血量；旅行或死亡后只重建尚未击败的已开始遭遇，不重复生成已领奖敌人。异常快照不能把异地图 Boss、错误职业或未来阶段的敌人带入这里，专属 ID 也不能带进原地图或深渊。

SaveData、EnemyRecord 与存档版本均未改，原 v1/v2 存档可继续。Campaign、地图、主角与同伴美术、字体、场景和所有旧 GUID 均保留。营地原六项选择的位置不变；七至九项对话扩展底板高度，让末行按钮留在背景内。

## 验证与限制

`tools/run_core_tests.py` 中的八组 Homeward 检查覆盖三职业真实行走与战斗、米拉实体在场、当地回调、顺序／一次性奖励、正常掉落、旧存档和异常敌人恢复。`tools/run_homeward_checks.py` 使用生产 Update、OnGUI 与 SaveStore，覆盖真实 E／C／数字／WASD／J／Q／Space／Z 路径、手帐／地图、两种交付结果、回信、暂停、校验和与旅行／死亡恢复。可追加 `--capture-dir .starfall-checks/layout` 生成离线界面证据。既有战斗、任务、厨房、档案、对练、手柄瞄准、河岸与 Boss 回归继续执行。
