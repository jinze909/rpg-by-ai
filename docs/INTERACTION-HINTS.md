# 靠近目标时的状态说明

原来的E／手柄B名称提示增加一行只读状态，仍针对实际最近的交互物：

- 木材、月光草与矿石：可采集；已经采集时提示回镇休息后更新。
- 杏的田地：空置、还需多少模拟秒成熟，或已经成熟。提示中的「交谈」表示打开杏原有对话，种植与收获仍需选择原选项，不会因靠近或读提示提前消耗种子、收获或交付委托。
- 旧路封印：所需第几枚星核的探索能力、可以解除，或旧路已经开启。
- 旧日补给箱：入口封印尚未解除、可以取补给，或补给已取但仍可重读原记录。

居民和其他目标保持原来的单行名称提示。最近目标、同距离顺序、交互范围、E／B／R行为、路标与任务导航不变；不改变任何机关、时间、费用、奖励或存档字段。作物倒计时沿用原60秒规则，暂停与对话期间不会自行生长，旅店休息仍按原规则推进45秒。

新增状态卡优先在目标下方、上方或两侧选择HUD重叠较少的位置，四处都被界面占用时再考虑中央备用位置，并留在虚拟画布内；原面板淡化与前景威胁重绘保留。它没有按钮，也不阻挡场景鼠标瞄准和攻击，原动作控件继续保护自己的点击。

`tools/run_interaction_hint_core_checks.py` 检查只读查询及真实采集、休息、种植、收获、封印、补给与存档行为。`tools/run_interaction_hint_checks.py` 经生产Update／OnGUI核对实际E／B、名称与状态、两套HUD、语言／字号／分辨率、输入穿透与界面避让。离线画面与DLL编译不代表原生Editor／PlayMode／GPU／设备试玩；原生验收仍为 **NATIVE_UNVERIFIED**。
