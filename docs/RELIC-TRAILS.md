# 遗物来源追寻 / Relic source trails

在遗物页（G）的任意遗物卡选择“来源”，查看永久奖励来源、条件进度和当前下一步。已持有的遗物也能查看。返回按钮、Esc 或手柄 B 回到遗物页，保留所选装备槽；肩键沿原菜单顺序切换。原装备、卸下与记忆锻印操作保留。

| 遗物 | 原有永久来源 |
| --- | --- |
| 回潮瓶 / Tide Flask | 完成港口方案、击败潮壳海兽后，向米拉提交调查 |
| 琥珀种 / Amber Seed | 在余烬镇把水渠与药田升至二级 |
| 风蚀罗盘 / Wind Compass | 完成沙海光路与守护者后，向伊沃提交调查 |
| 断钟片 / Broken Chime | 解开高原钟阵、击败守护者后，向森提交调查 |
| 薪火徽记 / Hearth Emblem | 完成米拉、伊沃与森的三段个人交付 |
| 裂隙石 / Rift Stone | 实际结算深渊第三层或更深楼层：清层后在东侧地脉门结算返回，或选择祝福结算并深入 |

“追踪当前前置任务”只追踪已有且可推进的主线、远岸调查或同伴个人任务。尚未开放的区域先显示真实前置；个人交付沿用现有物资、原册与探索记录指引。来源完成与持有状态独立显示，不会根据旧标记补发奖励。

“查看水渠建设计划”打开现有城镇建设页；施工仍需身在余烬镇，并遵守原报价、确认和扣费规则。“查看深渊地图”只选择地图目的地；“返回当前远征”只关闭菜单。两者均不启动远征、不清层、不入账。进入第三层或只清空敌人不等于结算第三层。

查看与刷新页面不装备、不治疗、不改变已准备攻击、不消耗材料、不推进任务、不修改存档或随机数；只有主动追踪会更新原有追踪记录。没有新增存档字段、任务 ID、费用或奖励。

验证入口：`tools/run_relic_trail_core_checks.py` 检查原奖励交付、前置和存档连续性；`tools/run_relic_trail_checks.py` 检查生产 Update/OnGUI 的查看、明确追踪、返回、旧装备操作及双语布局。后者支持 `--baseline-ref` 对历史生产源码验证同一测试的失败复现。

这些离线检查与 Unity SDK DLL 编译不等于原生 Editor 导入、PlayMode、GPU 或实机验收；原生体验保持 **NATIVE_UNVERIFIED**。
