# 建设后的城镇 / Visible town projects

三项城镇工程的两个等级现在在世界场景中显示各自的外观。原有 B 菜单仍负责报价、确认和建设；返回世界后，已建等级直接决定摆设，不需要额外领取或触碰设施。

- **水渠与药田**：原药田旁增加低矮水槽与石沿，二级增加分流细节；原播种、作物成熟和试灌苗床保持各自进度。
- **驿站**：旅店附近出现开放式补给摆设；远岸已有营地也能看到补给。二级增加茶具和储备外观。休息、每天赠茶及制作仍只由原有交互结算。
- **记忆工坊**：铁匠附近增加低矮工作台、工具与二级设备细节；原锻印开放条件、费用和二级免硬币效果保留。

外观是原有 `save.projects` 的只读投影。没有新增存档字段、地图交互物、可领取资源、阻挡墙或奖励。零级不绘制新增摆设；旧地图装饰、草地细节和交互目标不替换。设施按脚底位置参与原有深度排序，完整边界参与裁切，靠近角色时保持人物可读。

专项入口：`tools/run_project_scenery_checks.py` 使用实际生产输入与 OnGUI 路径验证建设后的显示、裁切与排序、地图／交互隔离、旧存档和区域切换。旧场景固定摘要、原建设与供给、送水与作物、同伴跟随另做相关回归，不更改旧断言或固定摘要。

离线图像检查和 Unity SDK DLL 编译不等于原生 Editor 导入、PlayMode、GPU 或实机试玩；原生体验保持 **NATIVE_UNVERIFIED**。
