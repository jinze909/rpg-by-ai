# 气候状态反馈

玻璃沙海与霜钟高原沿用原探索 HUD 的状态栏。第一行显示当前热度／寒意和正在起效的来源：持续累积、绿洲、凉茶、竞速、已点燃火盆或已维护的避风路。第二行提示危险阈值，或当前危险与应对方式。超过寒冷惩罚阈值时也提示移速和耐力回复降低；警告使用金色文字。战斗预告、原 HUD 边界和鼠标穿透规则保留。

## 原规则保持

- 沙海暴露时热度每秒增加1.3，绿洲三格范围内、凉茶有效或竞速时每秒降低10。热度达到85进入原气候伤害区。
- 高原暴露时寒意每秒增加1.1。凉茶或已点燃火盆3.5格范围内每秒降低8；避风路只停止累积，已有寒意不会自动下降，仍可能减速或造成气候伤害。凉茶和火盆优先提供原有降寒效果。
- 寒意严格超过70时，移速降低0.55、每秒耐力回复降低4；达到90进入原气候伤害区。伤害仍由原一秒检测和受击规则处理，难度、护甲、守势、闪避及无敌间隔均不变。
- 暂停、对话、背包和命中停顿沿用原计时规则。使用凉茶仍消耗一份、清除热度与寒意、恢复耐力并提供180秒效果；火盆仍需原有两份木材。反馈读取不点火、不用茶、不领取报酬，也不推进剧情。

快照只描述当前区域与位置，不预测玩家移动、凉茶到期或横风带来的后续变化。不增加存档字段；旧档按原规则恢复气候数值、保护期限、物资和剧情。
