# 飞行投射物的 HUD 轮廓

基线 `8fee578`；恢复点 `refs/codex/checkpoints/projectile-witness-baseline-8fee578`。

旧 HUD 见证只在投射物中心进入面板时画一个18×18方框。方框不能表达箭矢方向、魔弹外形；尖端先擦过面板时也没有前景见证。本次仅替换这一显示实现，世界中的原箭矢、魔弹、尾迹、发射/抬升高度、颜色、碰撞、伤害与时钟不变。

新见证在 HUD 之后绘制暗底、亮边两个中空轮廓。箭矢跟随真实速度旋转，魔弹保留原外形；友方沿用青绿，敌方沿用危险橙。保守旋转画布范围同时用于面板渐隐与前景见证，中心仍在面板外时也能提示擦过边缘的轮廓。这是可读性范围，不是碰撞或伤害半径。

六张144×144遮罩来自已接受 `Effects.png` 的第8/9/10格：先隔离128格，透明度阈值96，再加8像素留白。原二值身体保持透明，4像素膨胀环形成亮边，8像素膨胀环形成暗衬。没有重画、替换原特效。`bake_projectile_masks.py` 默认只核验，`--write` 才显式重建派生数据；源SHA、像素、Point/clamp、无mipmap、不可读、无压缩与新GUID均有检查。

六张小遮罩为普通 Git 文件，启动时借用 Resources 一次加载。绘制不扫描原不可读特效、不生成纹理，也不按弹幕数量扩张缓存；退出不销毁借用资源。低特效、减少动态保留相同轮廓。世界以外菜单及对练完成回顾继续不显示战斗见证；一颗投射物重叠多块面板仍只画一次。

定向命令：

```sh
python3 tools/bake_projectile_masks.py
python3 -m unittest discover -s tests -p 'test_projectile_masks.py'
python3 tools/run_projectile_witness_checks.py
```

CI 保留全部旧回归并加入以上阻断项。实际 GUI/Core 记录及重建预览属于离线证据。**NATIVE_UNVERIFIED**：持证 Unity Editor 的正式 Frontier 场景、GPU/缩放观感、Player 构建与试玩仍未执行。
