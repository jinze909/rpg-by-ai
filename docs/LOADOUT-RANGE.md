# 艾妲的试装训练场 · Ada's loadout range

完成原基础练习，或找回第一枚星核后，在星落镇找到艾妲，选择追加的第五项「试装训练场」。原基础教学、三段战术训练及实战记录的入口和报酬保留。

## 玩家流程

- 选择一线目标、聚集目标或正面重甲。每个目标有300生命；它们站定、不攻击，使用正式普通敌人的命中、正面护甲、暴击、破势与受控规则。
- 使用现有移动、J／左键攻击、Q战技与闪避操作。可在背包切换武器、打法或装备方案，也可调整成长与遗物；菜单暂停本次计时。
- 首次被接受的普攻或战技开始计时，前摇和未命中的时间也计入。面板显示实际扣除的目标生命、每秒实际伤害、接触次数、破势及重甲绕后次数。超出剩余生命的伤害不计入；这不是单次招式的理论伤害表。
- 清场后保留并暂停本次记录，不自动刷怪。按「重置本次记录」重试，或手动换另一组目标；重复点击当前布局不会重置。按「结束试装，返回」回到开始位置。

目标不会追击，因此本场适合比较射线、贯穿、散射、范围、冰霜与正面／背后命中，不替代原战术训练的闪避反击与混战教学。墙体仍按原规则阻挡攻击。每次重置、换布局与离开都会清除本次未落地攻击、投射物和冰霜场，旧攻击不能击中新生成的目标。

## 安全边界与存档

本场不扣生命、不消耗炖汤或凉茶，同伴不出战；没有经验、硬币、掉落、熟练度、教程、实战记录或委托进度。世界时间与探索教程暂停。普通战斗的伤害、攻击前摇、耐力消耗和技能冷却保持原值；每次显式新开尝试恢复100耐力。

退出或读档使用既有 `sparringReturn` 记录恢复开始时的位置、生命、耐力与冷热状态。主动更换的装备、方案及成长保留。训练目标和本次统计不存档；存档版本与数据结构不变，旧档不需要新增字段。目标保留独立临时ID `79000–79002`，普通世界与深渊的异常存档均不恢复这些目标。

## 验证方式

`Assets/Tests/Frontier/RangeChecks.cs` 的七组核心检查覆盖解锁与原选项、实际战斗统计、三职业清场、边界隔离、重置及存档恢复。`python3 tools/run_core_tests.py` 同时执行这些检查与保留的核心回归。

`python3 tools/run_range_checks.py` 的五组离线运行时检查直接驱动生产输入、菜单与保存路径，覆盖27种职业／武器／打法组合、六种职业战技、真实300生命重甲清场、未落地箭矢与冰霜清理、暂停与装备方案、校验和存档、旧版缺字段存档以及中英／大字／低特效界面。可加 `--capture-dir` 保存一次性 OnGUI 记录；CI执行同一入口。

离线声明、OnGUI重建预览与实际Unity程序集编译各自只证明对应范围。Unity Editor原生导入、Frontier场景运行、实体手柄、GPU画面、Player构建试玩与性能测量保持 **`NATIVE_UNVERIFIED`**；未以离线通过代替原生验收。
