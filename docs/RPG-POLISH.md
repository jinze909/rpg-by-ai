# 星陨边境：十二项制作要求的落实与验收

本次继续在已经可以运行的《星陨边境：远岸来信》上打磨，保留九个地区、原主线与扩展剧情、三职业、三位同伴、城镇建设和六层深渊。视觉方向继续参考现代像素 RPG 的人物可读性、区域氛围与统一菜单；新增内容围绕“把答应带回来的人带回家”展开。

这里区分实际实现、已执行的离线检查，以及仍需在 Unity 中观察的表现。离线通过不能替代 Editor / Player 试玩；本环境没有 Unity 编辑器。

## 新的战斗取舍

打法在取得第一星核，或该武器熟练度达到1后解锁；已拥有的武器才可装备。三把武器各自记住选择。

| 打法 | 通用取舍 | 武器区别 |
| --- | --- | --- |
| 均衡 | 普通攻击无额外耐力费用 | 短剑第三击增加伤害与范围；猎弓远射；法杖命中爆炸 |
| 蓄势 | 基础伤害×1.4，间隔×1.3，每击4耐力 | 猎弓贯穿；短剑与法杖更重的单次攻击 |
| 流转 | 基础伤害×0.8，间隔×0.8，每击3耐力 | 短剑增加破势；猎弓三箭散射，每箭按该打法伤害再×0.65；法杖命中短暂冻结 |

普通技能通常耗40耐力，特定遗物提高到50；闪避通常耗20，特定遗物提高到25。攻击、闪避和技能竞争同一资源，炖汤、凉茶、完美闪避与职业回复提供调整空间。低耐力会给出明确提示。

重甲的正面普通攻击伤害降至原来的40%。绕后、攻击其预告阶段或职业战技能突破这个优势。射手在靠近时后撤，玩家可以沿侧面接近，或借地形阻挡箭。死亡记录会区分箭、扑击、范围攻击和环境伤害，给出下一次可实行的调整。

## 第一段冒险与实战练习

开场先接受莉雅的委托，移动、实际交互和追踪任务逐步引入。镇内教官位于 `(11,14)`；入门战斗三步未完成时，镇内指引会指向教官。也可在镇内暂停菜单选择“进入实战练习”。

1. 命中木桩，确认攻击与命中的区别。
2. 等待红圈预告，离开落点或利用闪避避开实际命中。
3. 用职业战技命中目标，完成综合练习。

训练不会损失生命、炖汤或凉茶，不计敌人击杀和战斗掉落。首次完成给1技能点、15硬币，重复练习不给永久奖励。退出练习会恢复原镇内位置并清除训练中的冷却与领域。旧玩家可直接继续原进度；设置中可重看入门，F1随时查阅十二类指南。

## 六条旧路与六份记录

前三枚星核带来的能力可以在入口附近按 `R` 或 `E` 使用，手柄按 `B`。这些路线增加地区内的发现，不改变主线必须经过的通道。

| 地区 | 所需星核 | 发现的记录 |
| --- | --- | --- |
| 荆棘密林 | 第一枚：藤封 | 留在树上的路标：森林为何阻断采矿道路 |
| 沉没遗迹 | 第二枚：浅水 | 没有盖章的渡船票：机关次序与人的约定 |
| 赤炉矿场 | 第三枚：断桥 | 少记了一个人的工时：机器为谁运转 |
| 雾港 | 第二枚：浅水 | 两种颜色的灯：航路和落水者争取同一份零件 |
| 玻璃沙海 | 第一枚：藤封 | 最后一杯水的分法：路线、阴影与长期回报 |
| 霜钟高原 | 第三枚：断桥 | 钟声里的名字：为什么不能只说“所有人” |

每处首次发现奖励30硬币、3记忆碎片、1炖汤、当前武器8熟练度。重复调查只阅读，发现会进入手帐的“世界记录”。原十篇记录继续保留，总计十六篇，支持分页。新“旧路寻宝”条目会根据已解锁能力选择下一处可探索目标。

## 界面、输入与视觉规则

菜单以深蓝背景、象牙白正文、金色目标和青色状态建立层级；任务文字与图形同时表达状态。所有菜单沿用同一侧栏、页头和返回位置，禁用操作无法获得焦点。打开覆盖/读档确认时，只能确认或取消。对话未读完时先翻页，最终选择后回到来源菜单。

| 操作 | 键盘 | 常见Xbox布局手柄 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 左摇杆 |
| 攻击 / 闪避 / 战技 | J或左键 / 空格 / Q | X / A / Y |
| 互动或解除封印 | E，封印也可R | B |
| 炖汤 / 同伴指令 | F / Z | LB / RB |
| 凉茶 | T，或背包按钮 | 菜单进入背包，A选择使用 |
| 手帐 / 暂停 | Tab / Esc | VIEW / START |
| 菜单焦点 / 确认 / 返回 | 方向键或Tab / Enter / Esc | 摇杆或方向键 / A / B |
| 菜单切换 | 左侧导航或各菜单快捷键 | LB / RB |
| 长对话翻页与选择 | Enter、空格或数字选择 | A |

实际手柄编号沿用Unity旧输入系统；不同平台、PlayStation或第三方设备仍需实机确认。当前没有新增自由重映射界面。

人物保持既有Viola动画图集，居民比例缩小到与主角相近；人物脚下阴影与背景遮挡淡化服务可读性。树林、雾港、沙海、高原、深渊用区域色调、水岸、雨雪、灯光与地形纹理区分。现阶段使用Built-In与IMGUI，光晕和色调为绘制效果；不宣称实现物理光照或切换URP。环境特效三档和减少动态效果继续可调。

## 存档与升级

关闭Unity后，将完整包内的 `Assets`、`Packages` 与其他 `ProjectSettings` 文件覆盖到已经能运行的项目；保留该项目自己的 `ProjectSettings/ProjectVersion.txt`。然后打开 `Assets/Scenes/Frontier.unity`，或使用 `Starfall → Play Adventure`。

自动存档仍使用 `Application.persistentDataPath/starfall-v1.json`，三个手动位置使用 `starfall-slot-1.json` 至 `starfall-slot-3.json`。原版本1/2的裸JSON均可读取，新增字段自动初始化。新游戏替换自动进度，手动位置独立保留。存档管理显示地区、等级、章节、时间和恢复提示。

写入先生成校验封套并验证临时文件，再替换主文件；可读的旧版本保留为 `.bak`。读取主文件失败时依次尝试备份和中断留下的有效临时文件。损坏主文件不会覆盖好的备份。读取另一旅程前先保存当前进度；保存失败会取消读取。

## 检查与实际限制

检查数量及结果见 [QA-REPORT.json](QA-REPORT.json)。

- `python3 tools/run_core_tests.py`：编译生产C#核心；本阶段21组，当前视觉与战斗升级后为25组，覆盖三职业主线、多方案协定、六层深渊与新增规则。需要Python与Mono。
- `python3 tools/run_layout_checks.py`：编译生产运行时配合离线Unity桩，实际运行菜单及存档文件检查，并检查中英文、两档字级、键盘/手柄提示和长对话分页。需要Mono、Python、Pillow与FontTools。
- Unity Test Runner 的 `Starfall.Tests`：当前包含相同25组规则与一项原生JsonUtility往返测试；本环境未运行此项原生检查。
- [previews](previews) 是生产OnGUI记录的离线预览，最终字体度量、动画和混音以Unity实际效果为准。

最终还需在有Unity的电脑进行Editor导入编译、从新游戏到阶段结尾的操作试玩、自动/手动存档退出重进、实际声音试听、目标平台手柄验证和性能观察。这些不能从离线通过推断为已完成，也不承诺对所有玩家都适合。
