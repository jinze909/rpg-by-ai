# Boss 遮挡的连续过渡

本单元接续 `cafe792`。八地原 Boss 在主角横距1.399→1.401格时，整只身体的 alpha 会从 .55 跳到1；只有 .002 格、.072逻辑像素的位移也能触发整幅图突变。根因是 `DrawEnemyActor` 的严格矩形布尔开关，和美术资源、动作帧或碰撞无关。

## 表现规则

- 保留原1.4格半宽、2.7格后向覆盖范围与 .55最低不透明度；侧缘、后缘向外 .8格使用径向三次平滑过渡，远离后完全不透明。
- 前缘与树冠不同：角色画在 Boss 前方时，Boss 不应被淡化。原 -.01格前界线以内的 .2格向内过渡，在 -.21格及更后方可达到完整遮挡；到 -.01格前界线已恢复不透明，早于主角/同伴排序翻转。
- 主角和实际选中的同伴分别提供遮挡权重，取最大值，不叠加。未选中同伴的旧坐标无效；同深度或前景的角色不提供权重。
- 所有活 Boss 走同一入口，包括 Signal Warden 与试机守卫的既有美术路由。普通敌人、Archive 普通守卫、训练替身、尸体、阴影、蓄力光点、警戒几何与固定 .9的 HUD 轮廓保持原样。受击闪白继续乘以身体 alpha。
- 计算只读脚底坐标，不使用时钟、特效档位或历史；没有新增纹理、对象、计时器、存档字段或 GUI 热路径集合。原动作选择、画布、UV、颜色、朝向和战斗规则未改。
