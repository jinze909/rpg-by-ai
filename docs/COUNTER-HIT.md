# 反击命中反馈

原有闪避反击窗口继续显示剩余时间与下一次普通攻击的50%加成。窗口在普攻起手时消耗；现在，真正命中还会在原伤害数字上方显示薄荷色「反击 / COUNTER」，让玩家分清获得机会、发动攻击和成功命中。

- 标记来自这次攻击捕获的 `ImpactProfile.counter`，不读取命中时已经归零的反击倒计时。剑击、飞行箭、贯穿箭与星火爆炸都沿用同一身份；途中切换装备也不会改写已释放攻击。
- 只有玩家所属普通攻击造成有限、正数的敌人生命损失才标记。蓄势、挥空、零伤害、职业战技、同伴攻击和没有实际扣血的基础教学不虚报。对练和试装训练的真实扣血接触可显示。
- 原伤害、暴击前缀、护甲、破势、能量支出、命中时机和奖励保持原结算。反击标记使用原 `number` 浮字的变体，不新增第二次伤害或额外奖励。
- 标记与数字分行，保留完整数字；共同上浮，并在最后0.2秒淡出。完整两行参与稳定避让、画面裁切和存活期回收，HUD移动到其上时在HUD之后补绘。普通浮字保留原布局。
- 不增加存档字段。暂停冻结原模拟时钟；旅行、死亡和读档使用原有的战斗状态与浮字清理边界。新增文字复用现有字体字形，不更换美术或既有GUID。

- `python3 tools/run_counter_hit_core_checks.py`：反击获取、起手消耗、真实命中、飞行攻击身份、排除项与原结算。
- `python3 tools/run_counter_hit_checks.py`：实际Runtime Update/OnGUI、双语/字号/画布、稳定布局、淡出回收与存档边界；`--baseline-ref` 可用相同测试验证旧版语义失败，`--capture-dir` 可导出离线OnGUI命令流。
- 完整Core与相关战斗、浮字、教学回归，以及Unity 2022.3.53f1真实DLL编译。

离线命令流和真实DLL编译不等于Unity原生导入、GPU渲染或硬件试玩。原生验收仍为 **NATIVE_UNVERIFIED**。
