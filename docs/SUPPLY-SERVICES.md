# 单份补给与材料购买

阿茴的制作炖汤、制作凉茶、购买炖汤及购买木材，杏的购买种子，以及营地的制作凉茶，使用统一的只读交易信息。原对话、选项次序、按键编号与手柄确认方式保留。选项显示配方或当前硬币总价；材料、硬币或完整产出的存放空间不足时显示原因并禁用，直接按原编号也不会扣费或关闭对话。

上限沿用旧存档规则：普通物品每类9999，凉茶999。一次购买必须放得下全部产出；例如木材9995时可购买4个，9996时不能购买，不会扣全价只给一部分。单份炖汤与凉茶制作和原批量备制采用同一容量规则。

原成本与产出保留：药草2、鱼1制作炖汤1；药草2、星晶1制作凉茶1；购买炖汤18硬币、木材4个10硬币，对应声望折扣仍为15与8硬币；种子3粒5硬币。最终支付前重新读取当前状态，不依赖先前显示的信息。查看和交易不自动使用补给、不治疗、不续期，也不改写已准备的攻击。

该修复针对原付费服务。没有新存档字段或容量升级，不改剧情奖励、采集、作物收获、免费营地赠品或成熟任务进度；旧v1/v2存档仍按原规则读取。
