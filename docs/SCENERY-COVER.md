# 连续景物遮挡与同伴可见度

本次 Visual Renaissance 单元接续 `6ab2cfa`。成熟地图的树木、棕榈、雪松和遗迹在原遮挡矩形边缘会从40%瞬间恢复为100%不透明：角色移动 .002 格（.072逻辑像素）就可能让整棵树跳变。旧路河岸已有连续过渡；本次将它推广到同类景物，并补上实际出场同伴的遮挡见证。

## 表现规则

- 原有8张成熟地图的47处景物改用连续过渡；旧路河岸67处已有景物保留原曲线。没有增加、删除、搬动或重新绘制景物。
- 主角遮挡包络仍为半宽1.4格、高2.7格；敌人仍为半宽1.6格、高2.9格。边缘沿用 .8 格径向三次平滑过渡，最低仍为40%不透明；远离后恢复完全不透明。
- 同伴仅在 `save.companion>=0`、即实际进入世界绘制列表时参与，使用主角包络。没有选中的同伴即使留下旧坐标也不影响景物。多名角色取最强遮挡，不叠加透明度。
- 过渡直接由世界坐标决定，不依赖帧时钟、方向历史、镜头、特效档位或暂停。减少动态与最低特效保留同样的可见度；没有新增纹理、缓动计时器或渲染期集合。
- 非遮挡景物、风动条带、完整图格/UV、排序及稳定同深度顺序、视口外两格准备范围、远景裁剪、地表、接地阴影、危险轮廓和 HUD 补绘保持原路径。居民/世界物件/倒地身体没有新增遮挡权重。

这修正移动跨越边界造成的透明度突变，不承诺场景切换、角色生成/消失或手动更换同伴时也具有时间插值。

## 真实验证

`tools/run_scenery_cover_checks.py` 执行生产 `DrawWorldDecoration`、完整 OnGUI 和实际键盘 Update。新增检查4/4；同一脚本以 `--baseline-ref 6ab2cfa` 只读归档旧源码，编译成功后为1/4：三组行为检查明确失败，原几何保护组仍通过。CI 新增该脚本，保留全部已有检查。

检查覆盖：

- 全部47+67处实际景物的横向、上下、转角 .002 格边界；中间透明度、径向过渡和原透明度上下限。
- 主角、敌人、有效/无效同伴、多人最大权重；时钟、最低/最高特效、减少动态、暂停、离开与重返相同位置。
- 真实 E 从镇内进入森林及310帧合法 WASD 路线：出现中间透明度，相邻帧最大变化从旧版 .6 降至 .1000723。这是该离线路线的实测值，不是所有速度/帧率的上限。
- 实际 `SelectCompanion` 和跟随 Update：主角在景物包络外，同伴独自被沙海棕榈/遗迹遮挡，双方每帧均处于可站立位置。保留既有跟随死区，不要求同伴每一帧都移动。
- 251处已绘景物及原地表/稀疏 Details 的非目标提交摘要，与不可变基线完全一致；仅允许遮挡景物 alpha 改变。完整 Core、存档/备份文件、GUI 状态、缓存、排序、HUD 威胁见证和完整范围裁剪保持。

相关地图3/3、威胁轮廓4/4、接地阴影4/4和真实 Unity DLL 五阶段编译通过。276组元数据、7项检查器自测及 LFS fsck 通过；478个受保护基线文件（含全部276份旧元数据、87项 LFS 引用）保持字节或 OID 一致。Core、Campaign、存档结构、原美术、金发主角身份与 GUID 未变。

24对前后生产 OnGUI 记录覆盖森林、棕榈、雪松、遗迹、河岸、同伴、真实走路及两种 HUD 档位；48张近似合成预览无估算文字溢出，代表边界/同伴视图已人工复看。日志和预览均保存在 ignored 的 `.starfall-checks/cover-*`、`layout/qa-cover-*` 和 `qa-previews/qa-cover-*`。
