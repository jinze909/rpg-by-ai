# 普通攻击轻点缓冲

普通攻击冷却、收招、闪避或受击恢复距离可衔接时机不超过 **0.12秒** 时，轻点一次 **J／手柄X／场景中的鼠标左键**，可保留一次普攻。完全就绪时仍立即起手；窗口之外的轻点不会延后自动攻击。按住继续使用原来的连攻节奏，不刷新缓冲的寿命、方向或目标。鼠标点在界面上不会留下场景攻击。

输入时保留朝向、指针世界坐标与当时锁定目标的位置。随后转向或轮换锁定，不会改写已接受的攻击；箭矢与法弹仍从实际起手位置的武器发射点飞向保留坐标。缓冲不提前扣耐力、推进连段、生成命中或施加效果。真正起手时重新检查费用，使用当时的攻击与暴击数值，再按原动作接触帧释放；起手之后沿用现有快照规则。

仅保留一个请求；再次有效轻点以最新方向与目标替换。待执行的战技／闪避优先于普攻，已接受的Q／闪避清除旧普攻请求。运行时新按Q／Y或空格／A会在本帧模拟前放弃旧普攻缓冲，即使该高优先级操作当前不可用，也不会先偷偷打出旧普攻并扣费。持续按住普攻保留原有重复行为。

命中停顿与模拟一起冻结请求寿命。暂停、菜单、对话、旅行、读取存档、新游戏、死亡恢复、装备／职业／流派／战技切换，以及训练重置／结束／结算，都会清除不再适用的请求。它不写入SaveData，不增加存档字段或迁移要求。

在世界中用键盘快捷键或手柄View／Start打开菜单时，菜单输入先于本帧待执行的普攻、战技、闪避和同伴指令：即使恰好冷却结束，也不会先起手扣费。同帧新按或持续按住的世界操作也让位给菜单。已经开始的动作不会被取消或退款，仍在进入菜单后按原规则冻结，返回后继续原接触与收招。对话、钓鱼和只关闭确认框而不打开菜单的按键保留原作用。

在实际移动后有可用交互目标时，E／手柄B先于同帧尚未起手的战斗输入与补给操作处理，并放弃待执行的普攻、战技、闪避和同伴指令。靠近铁匠开口或采集资源时，不再先花一次攻击耐力。已付费动作仍按原接触时刻结算；对话按原规则暂停，采集则继续世界模拟。空目标或当前不可交互的训练保留原战斗行为，训练阶段间的继续／结束交互仍有效。菜单优先级更高，此规则不新增存档字段。

`tools/run_attack_buffer_core_checks.py` 检查窗口、帧率、费用、攻击快照、优先级和生命周期；`tools/run_attack_buffer_checks.py` 通过生产Update验证轻点、按住、界面排除与同帧优先级，含十二个菜单入口在不同帧间隔的提前／精确就绪边界及已起手动作连续性。相关战斗回归及Unity DLL编译另行执行。离线输入声明和DLL编译不代表原生Editor／PlayMode／实体手柄／GPU／Player构建与手感验收，后者仍为 **NATIVE_UNVERIFIED**。

`tools/run_interaction_priority_core_checks.py` 与 `tools/run_interaction_priority_checks.py` 定向验证有效交互的请求清理、真实Update中的轻点／按住／冷却边界、移动后范围、已付费动作、世界模拟、命中停顿、训练及旧档连续性。运行时脚本支持 `--baseline-ref`，以相同检查验证旧源码能编译且复现原语义失败。
