# 战斗悬赏的真实目标指引

普通击杀、守护者、重甲三类悬赏原来共用祭坛坐标，即使当前目标是普通敌人、祭坛已平息或挑战尚未开放，也没有给出相应的下一步。本次沿用原悬赏和导航系统，只修正目标与提示。

## 使用

在 N／委托簿接取悬赏后，会按原流程自动追踪。也可在任务手帐选择悬赏再追踪。世界地图和金色路线读取同一份实时指引；显式设置的青色本地路标仍优先，清除路标即可恢复任务路线。

- **清理商路**：优先当前地图可接近、仍活着且会给原悬赏计数的敌人。
- **拆解重甲**：只选同样条件下的重甲敌人。
- **危险信号**：已出现且可接近的守护者会成为目标；尚未出现时指向真实前置或实际祭坛，包括侦察员、记录与石碑、矿石与升降机、港口方案与救援／灯线、镜面、钟阵。已经平息的地区祭坛不再当成可击败的目标。
- 目标移动后路线终点随之更新；目标死亡后改选下一目标。筛选会检查实际脚底与原寻路，空路径不一概当成不可达：已靠近当前格中心的目标仍使用原碰撞验证。

没有当前目标时，普通击杀和重甲任务会指向另一个可进入地区的入口。如果只有当前地区可进入，则提示经过余烬镇重访密林。进入地区后才按原规则重新生成普通敌人，读取指引本身不刷新敌人。

地区守护者都已平息时，已开放远征的存档会指向镇内真实地脉裂口；尚未开放时会指向主线／远岸调查的下一步。深渊内继续由原东门结算路线负责导航，守护者悬赏说明需深入第6层；若本轮守护者已死后才接任务，则提示结算后重开远征，不会虚构第二只 Boss。

## 保持的规则

委托簿在接取前与接取后都显示准确报酬：35硬币、30经验、3碎片；共同治理结局为4碎片。领奖前显示硬币、碎片的当前与领取后余额；若触发升级，也显示等级、技能点变化及生命回满。

领取会按当前存档重新核验容量：硬币999999、碎片99999、技能点99，以及经验整数存储范围。奖励无法完整保存时不会发放部分报酬，也不会移除已完成委托或推进轮换。先花费硬币、使用碎片或投入技能点，再返回领取即可。保存与读取仍保留 v2 中的已完成委托；v1 沿用原迁移规则。查看预览不会领奖或改变任务。

- 只有接取后的原事件计数。训练场、切磋、信号守望者与委托专用守护者不被误选为悬赏目标；巡逻、河岸、归途、档案等原本能计数的实战单位仍可成为目标。
- 矿石、钓鱼和深渊结算悬赏继续走原流程。达标后仍在 N 委托簿领取原报酬：35硬币、30经验、3碎片；共同治理结局仍额外1碎片，不能重复领取。
- 不改变敌人、Boss、门锁、潮汐、碰撞、实际攻击、刷新或报酬。练习、深渊、显式路标与教学的导航优先级保留。
- 不新增存档字段。旧 v1／v2 存档沿用原迁移规则，包括 v1 原本不保留正在进行的扩展悬赏；查询不改变经济、随机数、生命、剧情、敌人或已准备的攻击。
