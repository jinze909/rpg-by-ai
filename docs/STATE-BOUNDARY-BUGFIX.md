# 状态边界与潜在漏洞复查 · 2026-10-06

本轮在完整要求复查之后，继续检查读档、菜单换装、攻击前摇、飞行、死亡和训练之间的边界。沿用现有三职业、全部地图、AI、任务和存档格式，没有生成或替换角色素材。

## 已复现并修复的五类问题

| 问题 | 复现条件与影响 | 修复 |
| --- | --- | --- |
| 上一场景的屏障计时污染读档 | 在旧世界仍有 0.55 秒开门消散时，读取另一份已经开门、角色位于祭坛内的存档。复用 GameCore 与新建 GameCore 得到不同位置 | 在校验新存档的通行位置前清除旧开门计时。六个受保护地区均比较复用与新建实例的位置及瞬态清理 |
| 换流派后执行一帧旧攻击位移 | 短剑前摇期间暂停，切换流派或职业战技，再恢复。旧动作先移动身体，随后才被取消；铁匠的直接换装也绕过统一取消入口 | 实际流派/战技变化立即取消动作；铁匠制作及装备统一调用 Equip；每次移动前再次校验已捕获的武器、职业、流派与战技，覆盖旧代码直接修改字段的路径 |
| 弹体命中借用后来装备的属性 | 箭或星火已经飞出，暂停后换短剑、破势流派或重击连段。旧弹体可能使用短剑的破势倍率、震屏，并把击杀熟练度记到新武器 | 每个友方弹体在释放时记录实际发射武器、流派及原熟练度归属。直接命中、爆炸溅射与击杀均读取这份记录；普通远程命中不借用后来的重击震屏 |
| 最后一段有效飞行被提前丢弃 | 弹体剩余 0.025 秒，本帧推进 0.05 秒。原实现先删除弹体，遗漏仍有效的 0.025 秒飞行及接触 | 只推进寿命内的有效时间，完成分段碰撞后结束。命中只产生一次 Impact，未命中则在精确终点消散；年龄和发射高度过渡也只增加有效时间 |
| 训练入口取消死亡恢复 | 镇中受到实际致命弹体攻击后，在死亡姿势期间打开帮助并选择训练。训练清除死亡计时，角色生命仍为 0 | 死亡恢复期间拒绝进入训练；保留恢复标记和死亡姿势，正常返回旅店、恢复生命及移除恢复标记 |

额外加入统一帧间隔防护：0、负数、NaN 和无限值不会推进位置、造成伤害、删除飞行中的弹体或污染游戏时钟。此项也防止最后一段飞行修复在零时长帧上产生新的回归。

释放时的记录仅存在于运行中的 Projectile，不扩展 SaveData。暴击、原技能伤害、既有资源成本、任务、掉落和同伴/跨装备职业技能的熟练度归属规则保持；归属改为在释放时确定。已接受的金发主角、角色图集、握持关键帧和环境资源保留。

## 检查范围

- `ReusedLoadsMatchFreshWorldState`：六个任务屏障地区，读档位置一致且旧动作/弹体/开门计时清除。
- `ChangedActionProfilesCancelBeforeMovement`：流派、第二 Q、旧直接换装、铁匠已有武器装备及新武器制作。恢复时不再执行旧动作位移或释放。
- `FlyingShotsRetainReleaseProfile`：真实猎弓/法杖攻击释放、菜单换装、破势、轻重震屏、击杀熟练度以及爆炸直接命中和溅射。
- `ProjectileLastPartialFrameStillCollides`：最后一段接触、精确终点、无超时位移、无提前消失。
- `ZeroDurationTicksPreserveLiveFlights`：零/负/非有限时长，包含已经进入目标接触距离的弹体。
- `DeathCannotEnterPractice`：真实致命 Projectile → 死亡 → 帮助/训练尝试 → 旅店恢复。
- `MixedStateTransitionsMaintainWorldInvariants`：六个固定随机种子，每个 3,000 帧，覆盖全部三职业和十个地图索引。组合移动、转向、普攻、Q、闪避、装备、流派、战技、菜单暂停、旅行、存读档；共 18,000 帧。检查脚底通行、生命/耐力、敌人唯一身份、活跃弹体和当前动作身份。

完整原有回归继续执行，最终汇总见 [QA-REPORT.json](QA-REPORT.json)。新增七组同时接入 Unity EditMode 的 `UnityCoreTests`，在本地 Test Runner 可再次运行。

## 验证边界

测试使用实际生产 C# Core；UI、输入、存档与 Boss 流程使用生产 Runtime 加离线 Unity 声明记录。此环境没有 Unity Editor/Player；原生图形、音频听感、真实手柄、帧率和平台构建没有实机验证。这是一轮有复现与回归证据的修复，不能据此声称所有潜在问题都已经消失。
