## 必须保持明确的剩余原生验收

使用 Unity **2022.3.53f1** 打开 `Assets/Scenes/Frontier.unity`；在 Test Runner 执行 `Starfall.Tests` 和 `Starfall.VisualTests`。使用 **Starfall → Visual QA → Open Review Lab** 的独立测试场逐帧推进、解除冻结实战与原生截图；不会写入旅程存档。截图保存在 `docs/native-captures`。

在原生窗口实际连续走 30 秒、鼠标与手柄四向攻击、跨武器 Q、移动后的收招、怪物贴 HUD、涨潮待发动作取消、未完成/消散中/已完成的第一关屏障以及完整八 Boss 战；检查头部、脚底、武器、地面采样、实际音量和操控感。用 Profiler 查看 CPU/GC/帧时间；本次只证明指定容器复用与像素遮罩绘制期零扫描，没有提供真实 FPS 保证。

当前结论是：可执行的离线检查及已发现问题已处理，原生验证边界仍明确保留。不会把“所有可能问题已消灭”或“每个像素永远正确”作为未经证实的交付声明。
