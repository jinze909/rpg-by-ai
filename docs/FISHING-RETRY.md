# 再次垂钓 / Fish again

湖畔或河岸的一次垂钓成功、三次失误或三次超时结束后，仍按原规则返回世界并显示原通知。在原钓点安全停留时，世界画面会短暂提供鼠标便捷按钮：成功后「再钓一条」，失败后「再试一次」。点击后从零开始一轮，不再重复打开钓点对话。

- 这是可选入口，不改变 E／手柄 B 的原交互，也不占用闪避、攻击、战技或确认按键。仍可按原流程与老潮交谈、交付鱼、查看记录或离开。
- 按钮先显示为不可用，经过下一次有效 Update 才可激活。同一结算输入、重复绘制或旧回调不会自动开新一轮；重新开钓的当帧也不接受收线。按钮区域保护鼠标输入，点击它不支付世界攻击耐力。
- 暂停时隐藏入口并清除可点击状态，恢复后重新等待下一帧。入口恰好到期或失效的那一帧，上一帧的按钮区域仍保护鼠标输入。
- 在入口上开始的鼠标按压由界面保留至松开；入口到期或拖到世界中也不会把同一次按压变成普攻。松开后的新世界点击照常攻击。
- 入口持续八秒世界时间。只属于刚才的存档对象、区域、世界代次和原钓点；离开原地、改变钓点、出现危险、开始动作或排队战斗请求后失效。切换菜单、旅行、读档、新游戏和重新开钓也会清除。
- 重试会再次核对地点、地形、原交互对象、生命、安全状态与鱼的存放空间。已经付费的攻击、恢复阶段、闪避、受击以及待处理的战斗／同伴输入会阻止重试；拒绝不会取消它们。
- 原三次成功／三次失误、河岸三阶段时长、鱼饵规则、奖励、赏金、老潮委托和河岸记录均保留。重试入口不拥有奖励，也不会写入存档。

验证入口为 `tools/run_fishing_retry_core_checks.py` 和 `tools/run_fishing_retry_checks.py`，并回归原钓鱼输入、反馈、河岸流程和存档。离线输入、界面记录与 Unity DLL 绑定编译通过不代表硬件输入或原生试玩；原生状态仍为 **NATIVE_UNVERIFIED**。
