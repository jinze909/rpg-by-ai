# 查看并确认天赋重置

在职业成长页（K／菜单中的 Talents）点击底部「查看重置」，先阅读报价，再选择取消或支付20硬币重置。查看时不改变成长、生命、金币或世界时钟。

确认页显示三项天赋投入、返还点数、可用点数、硬币余额，以及最大生命和当前生命的前后变化。保留原有结算：三项天赋返还全部投入，价格仍为20硬币；最大生命重新计算，当前生命只封顶到新上限，不额外治疗。已学第二战技、打法、熟练度、遗物和装备方案保留。原来可以重置的地区、对练与试装训练继续可用。

- 取消是键盘和手柄的默认焦点。Enter／A可取消；主动切换到支付按钮再确认才执行重置。Esc／B取消后停留在成长页。
- 确认期间，父界面的投入点数、战技切换、侧栏与菜单快捷键暂停响应，避免一次输入同时修改成长与付款。菜单仍暂停原战斗时钟，已准备或已释放的攻击保留原快照。
- 每份报价只属于当前游戏、存档对象和世界代次。读档、换世界、死亡或换游戏后旧确认失效；余额、点数、天赋或生命变化后，旧报价的支付按钮禁用，需取消并重新查看。
- 没有投入点数、硬币不足或退款会超过99个可用点数时，可查看原因，无法付款。99是原存档加载器的可用点数上限；拒绝超额交易，避免重置后读档丢失点数。刚好99仍可全部返还。
- 报价与确认状态不写入存档。v1/v2存档、既有资源与GUID保持原结构。暂停期间不接受支付；失去焦点时取消旧确认。
