# Boss 弹幕释放预告

通用守护者准备重踏时，发射口周围会出现琥珀色短箭线：矿场监工的三连弹显示三条扇线，径向弹幕显示本次实际准备的各个方向。原重踏红圈继续表示落点。短线提示出弹方向，弹体仍按原射程飞行。

预告与真实释放共用 `BossVolleyPlan`。计划读取本次已承诺的 `AttackPhase`、朝向和下一次释放轮次；蓄力中血量跨阶段线不会改变已宣布的弹量、方向或速度。下一招正常采用新阶段。矿场三连弹、后续危险区域、径向弹幕和援军保持原顺序；原14点弹体伤害、速度、数量与冷却保留。

短箭线最多延伸2.4格，使用实际圆形弹体半径与原地形阻挡查询，以0.1格步长停止在障碍前。绘制高度与本地区实际弹体发射高度一致。林地冲刺时预告随当前身体移动，最终出弹点仍由实际移动结果决定。

预告在世界前景绘制；碰到状态栏、Boss生命条或快捷栏时，在HUD上方补绘。它参与原背景淡化规则，保持世界瞄准和按键响应。低特效、减少动态效果和文字大小不会隐藏必要的方向提示。

预告没有单独倒计时或缓存，直接从当前蓄力读取。暂停冻结原攻击时钟；释放、破势取消、死亡、旅行或读档会随原状态消失。旧路守望和试机守卫继续使用原有专用预告。没有新增存档字段，也没有改动已有资源或GUID。

验证入口：`tools/run_boss_volley_core_checks.py`、`tools/run_boss_volley_checks.py`、完整Core、Boss阶段承诺/弹体遮挡/星火/轮廓/专用Boss相关回归和Unity 2022.3七阶段DLL编译。离线OnGUI几何与DLL编译不代表原生导入、GPU渲染、Player构建或试玩通过，原生验收保持 **NATIVE_UNVERIFIED**。
