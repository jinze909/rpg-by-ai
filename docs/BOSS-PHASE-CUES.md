# Boss 阶段反馈

八地通用 Boss（包括深渊中的通用守护者）的生命条标出66%与33%两条阶段线。边界沿用原规则：生命恰好降到线时进入下一阶段。真实非致死命中跨线后，显示两秒的「阶段1 → 2」或对应阶段提示；一次命中越过两条线时直接报告1 → 3，不虚构两次转换。

如果 Boss 正在蓄力，当前生命阶段与已宣布攻击的阶段可能不同。此时持续显示「阶段2 · 当前预告仍为阶段1」，直到这次攻击释放或被破势取消。提示只说明当前预告：原有移动速度、攻击后的恢复等仍按各自原规则读取生命阶段，已宣布的范围、目标、弹量、伤害与释放时刻继续使用原来捕获的攻击阶段。

阶段提示位于 Boss 血条下方，无新按键或操作拦截。它参与原HUD遮挡区域与危险轮廓补绘；低特效、减少动态与中英文文字设置保留必要信息。查看菜单和暂停冻结模拟中的提示寿命，死亡、旅行、读档或替换敌人后不会重播旧提示。击杀不弹出存活阶段转换，旧路守望、试机守卫与安全训练继续使用各自原规则。

数据只在当前运行中保存，没有新增存档字段、资源依赖或既有GUID改动。读取提示不治疗、不伤害、不消耗耐力、不改写已经准备的攻击，也不产生奖励或随机数。
