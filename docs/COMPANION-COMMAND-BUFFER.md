# 同伴指令的近就绪轻点预输入

## 玩家操作

Z、手柄RB与探索／战斗HUD的同伴按钮，在指令冷却最后 **0.12秒** 接受一次轻点。界面短暂显示「等待指令」，保留真实冷却数字与未就绪外观；到期才进入原「准备指令」。超过窗口的按键或点击不会排队，持续按住也不会刷新请求。

旧版三位同伴在冷却最后0.12秒收到Z／RB后，会直接丢失该输入；冷却归零仍需松开重按。实际Runtime输入已在60、50、30、25与20帧间隔复现该差异。

## 原规则与时钟

- 请求阶段只记录同伴身份、世界与存档归属、装备配置、按下时的方向及目标点。不提前缩短冷却，不提前取消自动支援，不生成箭矢、治疗、防护、领域或施放回执。
- 冷却实际结束后，按与帧末新按Z／RB相同的时点启动一次；新动作的已过时间为0，仍需完整 **0.2秒** 准备，动作总长仍为 **0.52秒**。本次伤害、羁绊与命中配置在真正起手时取得快照，之后不借用新的装备或瞄准。
- 原指令冷却保持 **18秒**，盟约结局保持 **12秒**。米拉的治疗／耐力／防护、伊沃三发贯穿箭与森的寒星领域均使用原接触规则、数值和真实回执。
- 以本帧之前的冷却与请求剩余寿命比较到期边界，避免较长一帧延长窗口或让准备提前推进。Hit Stop与视觉检查暂停冻结模拟时钟。
- 玩家自己的普攻、战技与闪避输入独立运行，不会清除同伴请求；反过来也不会吞掉玩家预输入。排队期间原自动支援继续，真正接受手动指令时才沿用原手动优先规则。

## 边界与存档

进入菜单、对话、应用暂停、死亡、训练、换同伴、旅行、读档或新游戏会清除旧请求。实际复试清场也会退休该场尚未派发的输入。清理只影响尚未起手的请求，已经接受的动作仍按原暂停规则保留。直接替换存档、改变世界代次或装备配置也不会把旧瞄准送给新状态。保存当前进度本身不执行或丢弃仍在本次模拟中的请求，但冷却、预输入及其引用均不写入存档，读档不会自动发出旧指令。

未修改 SaveData、EnemyRecord、存档版本、地图、剧情、角色素材或已有GUID。
