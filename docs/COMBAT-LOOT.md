# 战斗战利品回执

击杀发奖后，世界界面左侧显示约三秒的只读回执。有效期间继续击杀会合并本组硬币、经验与材料，并重新计时。材料只有一种时显示原物品名称；多种材料显示对应背包图标与数量。极大数量显示 `9999+`，表示至少9999，实际余额与奖励不受显示影响。末段淡出，低特效和减少动态仍保留回执；鼠标可以穿透它瞄准与攻击。

普通敌人的现有奖励是6硬币、12经验与一份相应材料；主线守护者仍是70硬币、80经验与一份星核碎片。回执记录已经执行的奖励，经验按发奖量显示，即使本次奖励触发升级、经验余额结转，也不会显示负值。玩家、同伴、战技、已释放弹道和冰霜领域造成的真实击杀共用同一发奖入口，不重复发奖。原升级、Boss与剧情通知保留。

深渊击杀只增加本层未结算的硬币、经验和碎片，不增加普通材料。回执标注 **未结算／UNBANKED** 并提示到东门结算；场景掉落提示使用碎片图标。深渊守护者倒下也不再声称战利品已经结算。选择祝福深入或结算返回会清除旧的未结算回执，离开／倒下时原有本层收益损失规则保持。回执只汇总近期战斗奖励，不是本层总余额；根回声、结算附加奖励、任务与交易继续由原界面说明。

原教学、艾妲切磋与试装场、伊沃试机、信号守望者及旧路复试保持各自的奖励入口，不产生普通击杀回执。暂停、菜单和对话隐藏回执并冻结模拟寿命；恢复后可继续读剩余时间。进入训练、旅行、读取存档、新游戏和死亡恢复会清除旧回执。它不进入SaveData，不增加版本或迁移字段，不改变现有资源与GUID。

`tools/run_combat_loot_core_checks.py` 验证实际发奖、升级结转、不可变合并、深渊结算及生命周期。`tools/run_combat_loot_checks.py` 经生产Update／OnGUI和SaveStore验证文本、图标、输入穿透、威胁可读性与旧存档。画面证据为离线记录，Unity DLL编译另行执行；原生Editor／PlayMode／GPU／实体设备／Player构建与试玩仍为 **NATIVE_UNVERIFIED**。
