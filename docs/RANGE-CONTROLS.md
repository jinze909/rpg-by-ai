# 试装训练场的键盘与手柄控制

艾妲的自由试装训练场原来只在世界画面上提供鼠标换靶、重置和结束按钮。本次为这些操作补齐键盘和手柄入口，沿用同一训练场与结算规则，没有增加快捷攻击键、奖励或新的存档字段。

## 使用方法

1. 按原流程到艾妲处选择试装训练场。基础教学、三段战术训练及其原报酬保留。
2. 在试装中按 **Esc／START**，在原暂停菜单选择「试装训练场控制」。也可点击训练记录面板下方的新入口。
3. 在控制页用方向键／摇杆移动焦点、Tab 循环焦点、Enter／A 确认，也可用鼠标。可选择直线、聚集、正面重甲三种布置；当前布置不可重复确认。
4. 「重置本次记录」沿用当前布置，清除旧攻击和记录，重新开始。「继续试装」回到同次尝试，保留目标、攻击与记录。「结束试装，返回」按原规则恢复进入前的位置、生命与耐力，保留自行调整的装备和成长。
5. 控制页按 Esc／B 返回暂停菜单，再次返回即可继续试装。清场后的结果也可用同一控制页重置、换靶或结束。

## 行为与安全边界

- 控制页暂停世界与训练计时，只读取原有目标布置、实际伤害、命中与用时，没有第二套计分或计时系统。
- 世界中的 E、Enter、普攻、战技、闪避和原鼠标按钮保持原语义；新菜单不占用战斗按键。
- 入口仅供当前试装训练使用。基础教学、三段对练、普通世界与标题设置不会出现该入口。
- 菜单操作绑定实际 GameCore、SaveData、训练返回记录与世界代数。读档、开始新游戏、更换训练或替换调试世界后，旧页面的训练操作失效；返回按钮仍可使用。离开到其他菜单会清除旧页面归属。
- 应用暂停、调试世界暂停、死亡等状态下不执行训练操作。训练仍没有金币、经验、熟练度、委托或战斗记录报酬。
- 未修改 Core、SaveData、Campaign、原地图、角色、美术、字体、场景和既有 GUID；只新增 Runtime 菜单与调用接线。

## 验证入口

- `python3 tools/run_range_control_checks.py`：走实际 Update/OnGUI、Esc／START 入口、Tab／方向输入、Enter／A、B／Esc、鼠标、三种布置、重置、返回、结束、旧会话拒绝、存档和双语布局。`--capture-dir` 可导出离线界面记录，`--source-root` 可对隔离生产版本做语义负向检查。
- `python3 tools/run_range_checks.py`、`python3 tools/run_sparring_checks.py`：保留原试装交易、真实命中、鼠标控件、旧档回位、原三段训练与世界 E／Enter 行为。
- 相关战斗输入回归与七阶段 Unity 2022.3.53f1 实际 DLL 编译覆盖新接线。

这些检查不等于 Unity 原生导入、GPU 字体渲染、Player 构建或手柄硬件试玩；原生验收仍为 **NATIVE_UNVERIFIED**。
