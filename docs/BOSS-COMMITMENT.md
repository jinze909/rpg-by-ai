# Boss 蓄力阶段承诺

Boss 已经开始预告的招式，保持起手时的生命阶段。玩家在蓄力中命中、让 Boss 跨过66%或33%的血量线，当前警戒圈、落点伤害、弹幕数量与速度、援军条件及后续裂隙伤害都不会突然升级。下一次蓄力采用新的生命阶段。

例如沉水遗迹的守卫从阶段1开始蓄力，警戒半径为2.4格、落点伤害为25。蓄力中被打入阶段2，这一招仍按原预告释放；下一招才使用阶段2原有的2.6格范围与28伤害。生命条和阶段数字仍实时反映血量。

八个正式地区的三阶段数值、招式、追击速度、释放动作、恢复冷却与成长规则保留。破势或森的指令仍能取消蓄力；取消后重新起手按当前血量准备。普通敌人与旧路守望的独立三招机制保留。Q缓冲、接触帧、瞄准、闪避时机与主角外观均未修改。

## 实现与存档

`Enemy.attackPhase` 只记录本次准备阶段；`AttackPhase` 仅在有效 Boss 蓄力状态中读取它。实际 AI 在宣布招式之前捕获阶段，警戒绘制与实际接触继续共用 `EnemyAreaRadius`。攻击结束或取消后回到实时血量阶段，下一次准备覆盖旧捕获。未准备、零值或非法捕获的测试／编辑器场景沿用实时阶段。

`SaveData`、`EnemyRecord` 与数据版本不变，招式捕获不写入存档。暂停冻结原招式；v1/v2读档保留 Boss 血量，沿用原有规则重新给出完整预告，不恢复玩家没见过的半段蓄力。地图、剧情、奖励、资源、Unity GUID及金发主角身份保留。
