# 装备方案与战技指南 · Battle plans & technique field notes

把已有的武器、九种打法、六件遗物和职业战技组织成三种常用配置，在艾妲的对练中比较，再带去探索或 Boss 战。所有配置属于同一位金发主角；原职业、数值、制作与学习条件保留。

## 三个装备方案

先通过原背包、职业成长和遗物菜单选择装备。按 **I → 装备方案**，选择位置1、2或3，再按“记下当前装备”。每个位置保存一把武器、这把武器的打法、当前职业的已学战技，以及两个遗物槽；空遗物槽也可以保存。

换装试验后，选中已存位置，按“应用方案”完整切回。其他武器的打法保留。方案不改变天赋、职业、同伴、技能点、成长、物资或剧情；也不会回复生命／耐力、退还施法消耗或刷新冷却。已经发出的飞箭与寒星领域继续按原来的起手伤害与归属结算。真正改变装备会取消尚未完成的攻击／战技准备，遵循原换装规则。

选择已存方案后，按 **数值对比** 查看当前装备与该方案的六项数值及差值：首击／每箭伤害、普攻间隔、普攻耗能、战技耗能、闪避耗能和步行速度。按“装备详情”可回到原有装备、战技与遗物说明；原来的应用、覆盖和清除按钮仍可使用。查看不会换装、治疗、花费耐力、推进冷却或改写已准备／已飞出的攻击。合法但尚未解锁的方案可预览理论效果，应用仍按原条件拒绝。

背包中的“武器与打法比较”使用同一接触伤害口径，并保留两位小数供比较：短剑显示首击，弓显示每箭；流转弓一次散射三箭，耗能仍按整次攻击计算，不能把三箭视作必定命中。数值跟随当前成长、生命、增益与地区，连击、反击、暴击、护甲与星火爆炸余波另计；查看不会改变装备或已经准备、飞行中的攻击。

对比使用此刻的生命、武器熟练度、遗物等级、食物／远行餐、地区与深渊祝福等条件。它显示非暴击的普通首击；流转弓显示三发箭中每一箭的伤害，不把三箭或星火范围伤害合并成保证伤害。连击、反击、暴击、护甲和爆炸余波另外结算。天赋、成长与职业不随方案变化，方案继续只保存装备选择，未增加存档字段。

覆盖已有位置与清除方案都需要确认。Esc／手柄 B 先取消确认，再从方案返回背包；清除方案保留现在的装备。相同的当前配置不需要重复应用。方案与旅程一起保存，三个位置相互独立。

应用前逐项核对所有权：武器已制作、该武器打法已解锁、第二战技已学会、遗物已发现且不重复。尚未解锁的合法保存方案会显示原因，不能部分装备或代替解锁。第一枚星核或对应武器熟练度1仍按原规则开放打法；第二战技仍需要等级5、技能点1。

背包的武器比较现在显示所查看武器的熟练度等级、总点数和下一级所需点数；下方进度条表示当前这一级的进度，满级后保持全满。职业成长页显示当前装备武器的同一进度。查看未制作武器或切换比较目标不会装备武器、花点或获得熟练度，仍须使用原来的确认按钮。

原成长规则保持：每20点升一级，最高5级／100点，每级增加2点基础伤害，最终攻击仍受武器、打法等倍率影响。合格普通敌人击败后+2、Boss+10，首次旧日补给+8；训练不提供可刷取的成长。已发出的飞箭与领域仍归起手武器，切换装备后不会把它们的战果算给新武器。已有第一枚星核时，无须再等熟练度解锁打法。

## 在花技能点前了解战技

按 **K → 战技效果与用途**，或从装备方案进入指南。基础与第二战技并排显示实际范围／倍率、用途和取舍；当前职业保持不变。达到条件后可在指南学习第二战技，消耗原来的一点；学会后两种战技免费切换，原成长菜单的操作也保留。

| 职业 | 基础战技 | 第二战技 |
| --- | --- | --- |
| 先锋 | 护盾震波：3.1格、伤害×1.9、护盾3秒 | 震地反击：3.8格、伤害×1.65、护盾4秒，清除附近敌方弹并提供更强控制 |
| 游侠 | 扇形箭雨：五箭，每箭伤害×1.25，覆盖多个方向 | 穿林一矢：一发贯穿箭、伤害×3.4，适合成一线的敌人 |
| 星术师 | 星火新星：4.5格、伤害×2.3的一次范围爆发 | 寒星领域：固定在脚下4格，持续4秒、五次伤害各×0.4并短暂冻结 |

这些是原有战技。接触时间0.28秒、完整动作0.62秒、冷却3.5秒；基础消耗耐力40，装备薪火徽记时消耗50，沿用原技能治疗规则。墙体仍阻挡箭与范围攻击。指南显示当前消耗，不提供新伤害或冷却加成。

寒星领域与森的指令现在各自完成已释放的领域，不再让后一个领域取消前一个的剩余脉冲。每场仍固定在各自释放时的位置，保留起手伤害与玩家／同伴归属，独立持续4秒、结算五次原倍率伤害；重叠时分别命中，冻结时长取较长的剩余时间，不相加。换装不会改写旧领域，菜单暂停其时钟，旅行、读档、死亡与训练重置会清除全部旧领域。

艾妲的战术对练允许打开背包、切换方案，再继续真实攻击与 Q 试用。准备菜单暂停原世界和训练时钟；安全退出仍恢复训练前的生命与物资，同时保留你主动选择的装备。方案没有额外训练报酬，首次完整对练的原奖励保留。

## 存档与验证

SaveData v2 只追加可缺省的 `battlePlans` 三槽数组与普通数据记录；原字段、存档封套／校验和、备份、EnemyRecord、地图和所有 GUID 保留。原 v1/v2 存档默认三个空位置，不凭空解锁装备。异常索引、重复遗物和越界记录会被拒绝，合法但未解锁的记录保留供之后使用。空位置使用默认关闭的 `recorded` 标记；无论读取器保留空引用或生成默认记录，都不会凭空创建方案。这个设计避免依赖 Unity 内联空引用的表示方式，依据 [Unity 2022.3 序列化规则](https://docs.unity3d.com/2022.3/Documentation/Manual/script-Serialization.html) 与 [JSON 字段规则](https://docs.unity3d.com/2022.3/Documentation/Manual/JSONSerialization.html)；原生测试仍未执行。

八组共享核心检查覆盖三职业、三槽复制隔离、原子应用、真实攻击／战技接触、旧飞箭与寒星领域归属、成长／经济／生命／冷却保护，以及旧档与非法记录。`tools/run_battle_plan_checks.py` 覆盖生产 Update／OnGUI、真实按钮和键盘／手柄焦点、覆盖／清除确认、原学习费用、实际 SaveStore／备份恢复，以及艾妲对练中的 J 猎弓命中与 Q 穿林一矢清场。可用 `--capture-dir .starfall-checks/layout` 生成离线中英界面证据；既有核心和 Runtime 回归继续保留。

数值对比另有四组 Core 专项（`python3 tools/run_battle_plan_stats_core_checks.py`），验证与真实换装、出手及扣能一致，包含条件加成、流转弓、只读查询、缓冲输入与旧档。`python3 tools/run_battle_plan_stats_checks.py` 通过生产 Update／OnGUI 检查比较按钮、键鼠／手柄、应用／确认、双语布局与只读绘制。它们不替代原装备方案检查。

`python3 tools/run_frost_overlap_core_checks.py` 与 `python3 tools/run_frost_overlap_checks.py` 定向验证寒星领域与森指令的双向施放、独立脉冲、固定位置、原伤害／耗能／冷却、归属和清场边界。后者直接驱动生产 Update／OnGUI；可用同一测试对旧生产源码复现领域互相覆盖的问题。
