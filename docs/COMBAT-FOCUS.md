# 战斗锁定 · Combat focus

在世界中按 **V**、按下右摇杆 **R3**，或点击 HUD 的「锁定目标」。从12格内、当前地形没有挡住的存活敌人中，优先选择接近瞄准方向的目标，距离也参与选择。目标脚边的静态青色角标表示当前锁定，完整生命的目标也显示原生命条。再次使用相同操作解除。没有可选敌人时不出现额外按钮。

锁定后按 **X**、点击新增的「切换目标」，或按手柄 **L3**，可直接切到另一名可见敌人；**Shift+X** 反向切换。目标按你周围的位置顺序轮换，同方向时依次比较距离与敌人身份。循环到末尾会回到开头；死亡、遮挡和超出12格的敌人会跳过。只有一个目标、尚未锁定或已失锁时不切换，也不会把普通操作变成自动锁定。V／R3仍只负责原有的锁定与解除。

切换只改变后续出手。已经起手的普攻、已缓冲的 Q、已释放的箭与星火仍保留各自的方向与目标快照，不会取消动作、退还耐力、重置冷却或变成追踪弹。菜单、倒下、旅行、读档和训练重置仍按原规则清理锁定。新按钮保持原解除按钮的尺寸与位置，仅在确有另一个可选目标时出现，并参与同样的指针保护和危险淡化。

锁定让普攻与指向型 Q 在每次接受输入时对准同一敌人的当前位置。可以后退或侧移射击；闪避仍沿移动方向，站定时使用当前瞄准方向。范围型护盾、新星与寒星领域仍按原范围和位置规则释放，锁定不会把它们变成远程追踪技能。

招式起手时冻结方向与目标位置。敌人在前摇中移动，不会扭转已经起手的攻击；飞出的箭和星火继续沿原轨迹，墙体照常阻挡。因此仍需判断出手时机，锁定不保证命中，不修改速度、伤害、耗能、冷却、暴击或破势。

目标倒下、被移除、离开12格或被地形遮住后失去锁定，重新进入视野也需要手动选择。不会自动换到另一名敌人。菜单、应用暂停或失去焦点、死亡、旅行、读档、新冒险以及训练重置都会清理锁定；退出菜单后可重新锁定。自由瞄准仍为默认方式，鼠标和右摇杆方向在解除后按原规则接回。

三职业、原教学、三段对练与试装训练场共享相同机制。低特效和减少动态保留静态标记。新按钮参与原危险遮挡淡化和轮廓重绘，只有实际按钮区域阻挡指针攻击；目标角标本身不拦截输入。原主角美术、场景、地图与成熟战斗内容保留。

锁定只持有当前世界的敌人引用与会话身份，不存储敌人ID，不追加 SaveData 字段或升级版本。旧 v1/v2 存档继续沿用原读取、备份和训练返回规则；读取不会凭空锁住恢复出来的敌人。
