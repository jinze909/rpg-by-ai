# 星陨边境 · 美术与动画规范

## 身份与视觉方向

Existing playable player sprite is the source of truth：`Frontier/ViolaMoves`。奶油金短发、侧分额发、翘起的发束、浅肤圆脸与小巧年轻比例固定。先锋、游侠、星术师是同一个人。红粉长袖与棕色基础服装是三个装备版本共同保留的内层。新增铠甲/披风/法袍不盖住发型或更换脸。

沿用现有 WorldProps 的像素绘画：有组织的色块、可辨认的石材/木纹/布料/金属，暖色受光与偏蓝阴影；不引入写实照片、厚重黑色漫画描线或霓虹高清特效。画像可以放大展示细节，人物身份、衣服结构和材质必须与小人一致。

## 动作与判定

所有动作由 Core 的动作时间轴驱动，渲染与命中事件读同一时钟。输入消耗与冷却规则保留；普攻/战技的伤害和远程生成延后至接触/释放帧。起手期间锁定攻击方向；不能在按键第一帧提前掉血。装备变化和旅行取消未释放动作，避免旧武器攻击错误套用新装备。

每个职业使用12格姿态：正面待机、背面待机、迈步A、迈步B、普攻准备、普攻命中/释放、战技准备、战技释放、闪避、格挡、受击、倒地。站立头部固定；行走依实际路程选择四相；普攻3个关键姿态（待机→准备→释放→恢复），持续沿用武器/打法的原interval。战技准备约0.28秒，再释放和恢复；闪避0.18秒。受击约0.18秒，普通敌人死亡约0.65秒，Boss约1.4秒，玩家倒下约0.9秒后回镇。

北向额外使用每职业4格（迈步A/B、准备/释放）；南向每职业4格（普攻准备/释放、战技准备/释放），总计60个绘制姿态。左右镜像，不把朝右出手的姿态套在朝下判定上。剑的第三击与蓄势打法使用更重的准备/释放姿态。受击期间暂缓未释放动作，恢复后在可见释放姿态结算伤害。没有新增独立奔跑或格反系统，已有闪避与护盾使用各自动作。

外观跟随当前主武器装备，职业选择给出对应起始武器。切换装备时画像、HUD和小人同步；职业属性/Q技能仍来自原profession，不能偷偷改角色玩法。装备强化以武器符光表现。主角对话画像也引用同一外观入口。导入统一根据靴子接地点记录锚点，南向剑尖不能当脚底；运行时不再使用逐格补偿常量。

怪物使用待机、迈步、准备、命中、受击、死亡六格；原AI锁定目标、前摇计时和原命中条件不变。Boss 抬武器/收身/举杖→蓄势→释放→恢复；原1.1秒左右前摇根据阶段变化，落点同步原伤害时刻。收招表现不额外改怪物数值或AI冷却。

同行者每人12个关键姿态：待机、两步侧向移动、侧向准备/释放/指令、北向准备/释放/两步移动、南向准备/释放，合计36格。自动支援在0.16秒接触帧执行，Z指令在0.20秒接触帧执行；准备期间双脚停止移动。米拉的红辫、伊沃的棕发与护目镜、森的白发白须保持原NPC身份。同伴没有独立生命系统，不能为了补姿态另造受伤/死亡机制。

绘制的是关键姿态，脚步与武器运动由统一动作时间轴和离散姿态切换组合；不是把每秒的每一帧都独立绘制。所有渲染都必须服从实际释放时刻，不能以特效遮住缺失的身体动作。

## 解剖、握持与方向检查

每格都检查肩→上臂→前臂→手的连接；闭合握持必须落在武器柄上，法杖不能戳在胸前或悬空。主角先锋恰好一把剑、一面盾；星术师恰好一根法杖，另一手施法；游侠恰好一张弓，准备时一支搭弦箭，释放后手中没有第二支漂浮箭。箭袋内备用箭与飞行弹体分别检查，不能误读成重复的搭弦箭。

同一方向的待机、迈步、准备和释放保持持械手一致；左右镜像由渲染统一完成。北向真正朝屏幕上方出手，南向真正朝下方出手，不能只修改脸朝向。武器、弓弦、肢体、靴子、披风和Boss长肢不得被切格裁掉，不得带入邻格零碎部件。

原始作者图可能包含后来否决的姿态；[POSE-REPAIRS.json](POSE-REPAIRS.json) 指定最终替换，游戏只读取打包后的图集。人物图通过透明度分区和连通身体边界切格，环境/特效仍保留独立粒子所需的透明沟槽切格。打包先写临时文件，完整解码后替换；自动检查只能验证技术边界，解剖与逻辑必须逐格人工复查。

攻击类型决定反馈：剑/箭轻闪白与短暂停顿；重击较强冲击纹理、短震动；法术小范围聚能和消散。关键轮廓始终可见。命中停顿只暂停战斗推进，菜单/提示和设置仍可操作；减少动态关闭震动，保留姿态与命中信息。

## UI、特效与场景密度

UI 沿用靛蓝面板、金铜边、米白字、青绿状态；每种主要武器由单一外观映射供选择卡、HUD、背包和战斗使用。职业装备、当前武器和强化等级的变化必须可见。NPC画像保持各自身份。

预警用低透明填充、清楚边缘和收缩/进度信息，绘制在角色下方；投射物真实飞行，箭矢沿速度方向，法球有短拖尾，碰撞留下约0.2秒消散。特效宽度和粒子数量受effectsQuality控制，但警告信息和攻击动作不能关闭。

环境装饰按稳定坐标种子分布；道路中央和交互/任务物周围留白。约每12–18个空地格一个低矮细节，通行道只放稀疏裂缝/苔藓。前景树冠接近玩家或敌人时降低透明度。新增装饰不进入Blocked判定；房屋和水的可视底边仍对应原碰撞边界。涨潮时淹没格显示水面，退潮时显示泥地；不可通行的墙格增加前沿层次。判定仍采用原脚底碰撞范围，不把人物整幅立绘当碰撞盒。

阅读顺序：玩家→敌人→危险攻击→可互动对象→战利品→环境细节。所有批次必须放入余烬镇、草地、地牢与Boss区域检查；只看图集不能通过验收。

## 开发工具

重新打包图集需要 Python 3、Pillow、NumPy、SciPy：`python3 tools/pack_visual_atlases.py`。随后运行 `python3 tools/sync_unity_meta.py` 和 `python3 tools/check_visual_assets.py`。正常在Unity运行已打包的工程不需要Python或这些库。

## 连贯性规范（2026-10-06）

本场景的动画由生产 Core 的时钟和 OnGUI 图格驱动。不要向未使用的 SampleScene Animator 添加层或事件来替代实际修复。对应关系是：基础移动状态、攻击阶段、受击优先级、死亡状态；像素图格直接切换，不做全身缩放、时间驱动的身体上下跳或虚假的视觉位移。

主角、同伴的动作和四相迈步图统一256×256画布与(128,240)脚底、0.75显示密度；活着的头部为独立且不缩放的作者像素层；普通怪的新增迈步图也用192×192留白，显示大小乘192/128，保持原身体密度。Boss迈步用384×384、脚底(192,360)，显示大小乘384/320，保持原320图格的身体密度。改变留白大小不等于改变角色身高。九张新图集共116个迈步姿态，导入记录见 `ATLAS-IMPORT.json`；`pack_walk_atlases.py` 与 `pack_visual_atlases.py` 都调用完整注册入口，保留 `POSE-REPAIRS.json` 和 `FRAME-ART-REPAIRS.json` 中的已接受修复；不能留下未注册动作图。

四相按实际走过的距离选择：左脚接触、经过、右脚接触、经过。主角/同伴完整步幅2世界单位，普通怪按结构为1.35或1.8，Boss为2.8；停止、撞墙、受击、闪避不累计普通步行距离。脚步声来自同一距离钟的半步落脚事件，不另设定时器。站立居民目前没有移动AI，保持固定脚底，不用抖动伪装走路。

| 移动规则 | 使用条件 | 身体与判定 |
|---|---|---|
| Full | 无动作的探索移动 | 碰撞后的实际位移驱动迈步 |
| Reduced | 普攻收招、近战Q收招 | 70%输入速度，同时恢复迈步 |
| Attack Movement | 剑的起手与命中 | 沿锁定方向真实前踏0.34–0.45单位；遇障碍整体停止，不沿墙反复拉扯 |
| Stationary | 拉弓/普通施法的起手与有效帧、强力远程Q、受击与死亡 | 身体站稳；普攻收招可移动，强力Q动作结束后恢复 |

当前使用完整身体图格，因此普通远程攻击明确短暂停步。不得一边平移位置一边播放站立施法图。若以后新增真正上下身分层，必须一并替换移动规则与原生组合状态测试。

瞄准输入只转换一次；动作保存不可变方向，身体、武器、发射点、特效、前踏、命中判定都读它。移动方向只驱动行走朝向；收招允许准备下一次瞄准。身体有上、下、左、右姿态，鼠标投射物支持连续角度。没有宣称具备八套独立身体动画。职业Q临时使用该职业的动作武器，装备伤害与打法仍按原规则结算；普通攻击使用当前装备。跨职业换武器必须同时测试Q。

鼠标落在敌人身体绘制范围内时，以该敌人的真实脚底判定点瞄准，避免点击抬高的头部/胸口却射向其后方空地；弹体仍按起手锁定方向飞行，不追踪转弯。战斗血量、Boss条、消息等只读面板允许世界瞄准与攻击穿透，真正的技能、任务按钮和暂停按钮拦截点击。不能在敌人已可见的情况下，又把它藏在无法操作的HUD区域。

发射点由统一 `WeaponOrigin/WeaponHeight` 提供，按真实有效帧校准；发射闪光与初生投射物共用位置和高度。法师上/下法杖尖分别在脚底上方约82/67逻辑屏幕像素（含地面偏移），不能从胸口出生；高举杖尖的弹体用0.25秒平滑过渡到飞行高度，箭和Boss弹体保持各自高度。弓箭扇射共用弓的出生点，不能把五个发射点撒在身体周围。目标位于竖向武器侧偏时，锁定的瞄准来自武器口到目标的向量，避免直线瞄准却始终擦过目标。投射物与敌人的碰撞同时考虑弹体可见半径。贴墙时从脚底到武器尖进行遮挡检测，弹体不得从墙另一侧出生。飞行逐段扫墙和目标，穿透记住已命中的目标，爆炸不能重复打主要目标。拖尾随实际飞行年龄形成；失效弹体淡出，墙/目标碰撞产生对应冲击。

角色、尸体、效果、冷却与危险攻击共用模拟暂停与hit stop规则。普通箭/轻攻击不震屏；重击和Boss砸地保留克制反馈。世界使用共同整数逻辑像素投影，摄像机跟随只读位置，不读转身动作；测试场与正式运行共用阻尼。实际显示器与GPU的像素采样仍必须做原生验收。

树根和下部树干固定，运动集中在顶部树冠，每棵树有稳定的不同相位、速度和幅度。草地细节不因角色接近而消失。战斗HUD紧凑，威胁进入面板背后时降低底色并在其上补绘真实角色轮廓；文字、资源条保持清楚。HUD绘制区域与指针拦截区域必须出自同一份矩形表。

任务屏障必须封住整个禁入区域，并绘制相同边界。六个东北星核区域同时封住西侧与南侧，目标完成后0.55秒消散结束才解除碰撞；港口南侧救人路线保持开放。其他封印支路也必须通过四分之一格八方向连通搜索与快速移动测试。

## 本轮固定像素与导入契约

主角的活体头部来自 `WalkVanguard` 同方向帧，三职业使用同一张脸。行走不改变头部位置；攻击头部只跟随已注册颈部位置，不跟随整幅图的伸缩。同行者使用自己的 `WalkMira/WalkIvo/WalkSen` 身份。倒地完整绘制原倒地姿态，不叠加站立头部。上下闪避、防御、受击与倒地来自方向反应图；镜像按职业握持规则记录。

目标位置、身体朝向与武器附件在起手时一起快照；四方向附件不能再次用连续弹道选择方向行。释放、飞行、命中从同一实际出生点推进，近墙仍由扫碰撞拦截。

`ActorMasks` 为离线从源透明度生成的GPU绘制数据，44张遮罩提前加载，绘制期禁止首次扫描大图。源图保留readable，遮罩不可读、Point、无mipmap、无压缩。资源所有权区分借用与生成；销毁临时绘图对象不能销毁Resources资源。
