# 远岸来信 · 扩展说明

这次扩展继续使用原 Unity 工程、角色图集与星陨主线。新增内容从第一枚星核交付后开放，让远行有机会改变原故事中的最终对峙。

## 剧情的共同问题

每个地区都有人在坚持一种看似正确的责任，却把另一群人排除在账目之外。

- 雾港的灯必须亮，摆渡船却不断失去乘客。米拉的故事把一个被涂改的名字重新变成真实的人。
- 沙海的机器守着死去主人的约定，活着的人却没有水。伊沃试着让技术开始记录使用者，而不再只认主人。
- 高原的钟阵压住风雪，也压住求救声。森从替别人解释钟声，转向听见路上的人。
- 公会、药师、渔夫和铁匠的旧线索通过未寄出的信连接这些地区。厄洛面对的不再是一个抽象道德问题，而是原始记录与已经运行的新方案。

三个协定都能继续游戏；共同治理需要资源、建设与多方支持，作为额外争取出的路线。它开放和平对峙，但不自动替玩家完成原主线三项居民委托。

## 玩法互相提供理由

采集提供救援、修塔、建设与个人故事的材料；建设改善种植、补给和锻印；料理与茶支持气候探索；探索获得同伴与遗物；武器熟练度、专精与遗物给远征提供搭配；悬赏让回访旧区域仍有目标。

深渊把长期积累带进短期选择：当前层的收益还没有结算，继续走可以叠加祝福，返回可以保存成果。地图种子和敌人断点会写入同一份存档，读取时保留本层进度。

## 本版验证范围

实际 C# 核心的十二组检查覆盖旧主线、新地区各分支、三职业标准难度六层远征、和平路线、阵营条件、材料支付、气候、竞速、专精、遗物取舍、每日赠礼、存档迁移与敌人断点恢复。

运行时以离线 Unity API 桩进行语法与 GUI 绘制调用检查，并生成中英文预览。这些检查不能替代真实 Unity 编译、动画与声音检查、输入手感试玩或玩家反馈。本环境没有 Unity 编辑器，因此尚未完成这些验证，也没有生成平台可执行文件。

## 主要代码

| 文件 | 责任 |
| --- | --- |
| `Core/GameCore.cs` | 共享移动、战斗、成长与原主线 |
| `Core/ExpansionCore.cs` | 阵营剧情、同伴、气候、光路、竞速、建设、悬赏、深渊 |
| `Core/GameModel.cs` | 兼容旧存档的版本2数据与敌人快照 |
| `Runtime/FrontierExpansionUI.cs` | 新区域物件与地图、手帐、遗物、同伴、工程界面 |
| `Runtime/SaveStore.cs` | 沿用存档路径，读取版本1与2并保留备份 |
| `Tests/Frontier/ExpansionChecks.cs` | 新增真实规则回归检查 |

新增中文字体字形已随工程打包。后续加入剧情仍需扩充字形子集，或替换为完整的 Noto Sans SC 字体。
