# 冻结与破势的连携窗口

同一敌人受到多次控制时，取「当前剩余时间」与「新控制的原定时长」中的较大值。短控制不会缩短已生效的长控制，时间也不会相加。例如还剩0.9秒破势时受到0.45秒寒星脉冲，仍保留0.9秒；只剩0.2秒时受到同样脉冲，则刷新为0.45秒。

## 实际变化

- 森的指令仍在0.2秒释放，初始5格范围控制1.4秒，脚下4格寒星领域持续4秒、造成五次原有伤害。第一轮脉冲不再把刚生效的1.4秒覆盖为0.45秒。
- 寒星脉冲保留仍在生效的较长破势窗口。
- 玩家普通职业爆发、先锋第二战技、同伴初始冻结与真正命中触发的破势，使用同一重叠规则。先锋第二战技造成Boss破势时，不再把刚获得的1.1秒破势缩短成1秒。
- 控制期间沿用原血条金星提示；计时结束后敌人继续原行动。暂停仍冻结模拟，旅行和读档仍按原规则重建临时战斗状态。

## 保留的规则

没有修改控制的原定时长、命中范围、墙体遮挡、伤害、破势阈值与恢复间隔、冷却、耐力、寒星脉冲次数、投射物及其起手归属。委托守卫的排压与状态机仍沿用原机制。没有新增存档字段、动作、素材或Unity资源引用。

## 验证

`python3 tools/run_control_overlap_core_checks.py` 检查控制重叠、真实伤害与破势、控制到期及旧档连续性。`python3 tools/run_companion_tactics_checks.py` 通过生产Update／OnGUI驱动Q与Z／RB，检查真实释放、五轮领域伤害、暂停及敌人恢复行动。两者均能对旧生产源码运行语义负向验证。

原同伴检查中的几何测试会预先冻结目标；对应断言改为保留这份冻结的剩余时间，半径、伤害、领域位置与五次脉冲的原断言保留。
