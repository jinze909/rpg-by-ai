# 屋后合法落点的敌人追击

## 已复现的问题

雾港保留原地图、房屋和全部七名区域敌人。玩家从入口 `(5,14)` 正常步行经过 `(14,14) → (14,8) → (17,8) → (20,8) → (20,5.1) → (17,5.1)`，不需要闪避、无敌或重置敌人位置。玩家的完整脚底合法，但所在格子的中心 `(17.5,5.5)` 被房屋挡住。

旧寻路无法访问该格心，退回朝玩家的直线方向。实际生成的追猎者会卡在约 `(17,7)`，等待20秒仍距玩家约1.9格，最后五秒完全没有位移，也无法穿过房屋发起攻击。屋侧存在合法绕路，且未超出原追击范围。20与60帧间隔均能复现。

## 修复边界

- 原区域自然生成、允许脱战归位的普通敌人追击时，共用已经用于同伴跟随的精确脚底落点查询。正常格心目标仍调用原 `DirectionTo`；只有合法脚底所在格心受阻时，才搜索通往该实际落点的合法格心与短距离末段。
- 首段和末段检查完整脚底，实际移动继续经过原扫掠碰撞；速度、步态距离、首次8格警戒、已发现后10格追击、近身停止距离、视线与攻击距离均不改。
- 已承诺的攻击仍先于移动处理，保留起手时的方向、目标、前摇、伤害、释放与恢复。Boss、训练、任务专用单位、增援、深渊与脱战归位使用原路径。
- 同伴保留原跟随偏移、目标、速度和动作中原地准备的行为。寻路助手从 `CompanionFollowCore.cs` 移至 `ActorFootPathCore.cs`，沿用同一 `.meta` GUID；未改地图、角色素材、碰撞或资源引用。
- 复用现有寻路工作区，不增加逐帧列表或持久路径缓存。存档结构和版本不变，读档仍按当前地形重新查询。
