# 地脉远征规划 / Abyss planning

东侧地脉门在清层后显示本层未结算战利品、实际结算收益、当前三种祝福及下一层内容。六层地图、种子、敌人、落印、回声挑战、原奖励与风险数值保留。

- 祝福仍为同类相加、最多四层：利刃每层攻击 +15%，泉涌每层耐力回复 +4/秒，磐石每层受到伤害 -12%。正文显示本次远征的累计效果，按钮显示本次选择的增量和选择后的层数。
- 满层祝福保留原按钮位置，标为已满并禁用；鼠标、编号键、焦点确认和直接 Core 调用都不能借它结算、回复生命或进入下一层。可选择另一种祝福，或用原第四项安全结算返回。
- 三项均满的旧存档追加“保持祝福并深入”，只保留当前祝福并执行原有结算、治疗与下楼，不增加第五层祝福。
- 下楼仍结算本层、回复最大生命的 50%（不超过上限）并回满耐力。新增“继续观察本层”放在原选项之后，可回去完成第 2／4 层的可选回声。

预览按现有规则计算：当前战利品、共同治理协定每层额外 2 碎片、首次完成第六层的 12 碎片和 2 技能点，以及第三层起尚未领取的裂隙石。首通奖励不会在再次远征时重发。下一层提示只说明实际已有内容：第 2／4 层西北回声、第 3 层起的落印、第 6 层收割者；回声不是下楼条件。

武器比较修正了一个仅在不同武器熟练度与利刃祝福同时存在时出现的误差：候选武器的熟练度差值现在应用同一祝福倍率，预览与实际装备后相符。已装备武器的差值为零，实战伤害、速度、范围和耗能保持原公式。

没有新存档字段、任务编号、贴图或场景改动。v1／v2 存档沿用现有祝福数组及结算标记；已有资源和 Unity GUID 不变。
