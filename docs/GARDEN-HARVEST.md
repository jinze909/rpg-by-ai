# 药田收成预览与安全收获

与杏交谈时，原故事和选项顺序保持。附加药田状态显示未种植、尚需生长的秒数或成熟状态，以及当前水渠与协定对应的收成。已种植时显示药草、种子、硬币的当前与收获后数量；空田明确说明种植另耗一粒种子，不把尚未支付的成本混入库存预览。

原规则：种植消耗种子1，生长60秒；收成是药草 `5 + 水渠等级×2 + 水源协定加成2`、种子2、硬币8。加成在实际收获时读取。对话和菜单仍暂停原世界时钟，旅店休息仍推进45秒。

收获前重新核验药草与种子9999、硬币999999的存档容量。无法完整保存收益时，收获按钮不可用、成熟作物保留；不会部分发放报酬或推进「药田的第一份收成」。空间足够后再次收获，收益、收获见证和清空田地一起完成。重复请求不能领取两次。

## 多余种子

杏对话的所有原选项之后追加「整理多余种子」。打开时只查看，不扣除物资。确认页说明归还种子3、不获得报酬，并显示前后数量；不足3粒时不可归还。默认选项是保留种子，取消会回到杏的原对话。

只有当前确认页、身处杏附近且状态允许时才能归还；确认消费一次后失效。退出、读档、旅行或旧回调不会重复扣除。归还不改变田里作物、硬币、药草或任务进度，也不新增买卖收益。种子满额且已有作物时，可用此入口为下一次收获留出空间。
