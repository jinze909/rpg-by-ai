# 星火弹的飞行与消失衔接

基线 `8795620`；恢复点 `refs/codex/checkpoints/starfire-alignment-baseline-8795620`。

原 `Effects.png` 第9格的星火有朝右的亮头与朝左的长尾。此前本体及 HUD 轮廓固定朝右，尾迹和消失帧却沿速度旋转，向左或纵向发射时会出现头尾分离与消失瞬间转向。另一个问题是自然消失按 `explosive` 选帧：米拉的自动星火攻击没有爆炸伤害，因此被误选为第10格圆形魔弹。

没有替换美术、纹理、遮罩或主角外观，也没有改变发射速度、大小、伤害、碰撞、抬升高度、尾迹、寿命、冷却、输入、存档字段或 GUID。圆形魔弹保留原朝向，箭矢保持原表现。米拉自动星火、森自动星火与伊沃自动箭矢继续使用原攻击；实际 Z 指令仍分别为治疗、冰霜与三连箭。
