# 旧路守望 · The Signal Warden

完成「最后一班巡路」并向返乡侦察员交付后，他会谈起旧灯中的守路回响。密林第三处灯 `(23,9)` 提供自愿挑战；主线不要求击败它。回响借用巡路守望者的形体，守护旅人与森林根系之间的路，不是新增一只需要征服的森林野兽。

在第三处灯按 E，读完招式说明，选择「开始守望挑战」。回响有 300 HP，三招按固定顺序轮换；血量变化不会缩短已显示的预告，也不会改变其落点。

| 招式 | 预告与伤害范围 | 应对 |
| --- | --- | --- |
| 旧路冲刺 | 0.95 秒准备，锁定最长 5 格的通路；最后 0.2 秒沿通路冲刺，接触半径 0.65 格 | 向侧面闪开，不沿冲刺线后退 |
| 双灯落印 | 1.15 秒准备，锁定目标两侧相距 4 格的两个光圈，半径各 0.9 格 | 站入两圈之间的空隙，或离开光圈 |
| 分光散射 | 1.1 秒准备，四条慢速弹道，中央没有弹；从回响前方 1.7 格开始，飞行 4.5 格 | 沿预告的中央空隙接近，避开两侧弹道 |

各招释放后都有停驻的反击窗口。招式不会叠加主线守护者的全周弹幕、阶段增援或地区特殊攻击。预告、实际接触和遮挡后的边界重绘使用同一组锁定几何；场景中的根系和墙体仍会阻挡角色与弹道。既有受击、破势、Q、闪避与输入缓冲照常工作。

胜利使回响平静，自动一次性获得 **6 碎片、1 技能点**。它不产出普通怪物或主线 Boss 掉落，不增加守护者悬赏、主线击杀、职业熟练度或星核进度。手帐的第十二项「旧路守望」记录前置、开始与完成，金色指引跟随灯位或战斗中的回响。原侦察员谢礼、巡灯交付及全部主线内容保留。

同一密林存档保留回响 HP，读取后从安全停驻状态重新准备完整招式。离开密林或倒下结束本次尝试；巡灯成果和接受记录保留，回第三处灯可重新开始，回响恢复满血。死亡使用原有回镇与 10 硬币损失规则。保存格式未增加字段，仍使用既有旗标与敌人快照；旧存档不自动开始挑战。独立身份 `73000 / Boss / kind 3` 避免与森林守护者的完成标记、存档过滤和普通敌人分配器混淆。

森林守护者的现有图集提供回响的动作，淡绿色绘制区分身份；没有替换任何美术、字体、主角或既有 GUID。无需新场景、包、Inspector 配置或外部服务。

验证入口：`tools/run_core_tests.py`、`tools/run_signal_warden_checks.py`、`tools/run_watch_quest_checks.py`、`tools/run_combat_input_checks.py` 与 `tools/check_editor_syntax.py`。专属 Runtime 检查使用生产 Update、OnGUI 和 SaveStore；加 `--capture-dir .starfall-checks/layout` 可记录临时绘制证据。

这些工具验证生产代码的离线行为。Unity 编译、原生 GPU、音频、手柄、完整密林战斗难度与玩家手感仍为 **NATIVE_UNVERIFIED**。隔离普通森林敌人的编排测试不代表原生难度或完整地图的试玩结果。
