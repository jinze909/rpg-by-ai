# 莉雅的公会回话 · Lyra's Guild Evidence Trail

余烬镇的莉雅现在会随主线进度给出不同的简报。第一枚星核之后去沉没遗迹调查星核原本的作用；第二枚之后去赤铁矿场追查供能；第三枚之后前往星陨堡垒，询问屏障的代价。持有待交付的星核时，也会显示对应章节的回话。交付仍使用原第一项，仍给硬币40、木材3、星晶2和炖汤1，直接返回世界；新增足迹和下一站提示，不强制打开新的对话。

在莉雅处按 E，读完简报，选择新增的「共读调查记录」。前两项的编号与功能保留；结局后的原三项也保留。调查回顾逐项列出密林的侦察记录、遗迹石碑与矿工日记：找到的可以全文重读，缺失的只显示来源地图，不会把未知记录当成证据。

三枚星核交回后，若已经找回全部三份记录，可「记下公会回话」，把它们连成一条调查线：采矿伤害森林根系，星核维系土地，堡垒屏障抽走城外生机。莉雅保留巡路队的解释，但最终选择仍属于玩家。主线通关、镇民支持、远岸协定、和平方案及三种结局均沿用原条件；可完全跳过这段回顾继续冒险。

第三次交核后还开放「巡路队的回信」。它回应开场带来的旧信；若实际读过密林树上的路标或旅店赊账簿，回话会补上对应内容，救回的侦察员也会成为回信的第一行。结局后可继续重读。首次收下回信和首次记录调查各留下双语足迹，以后重读不重复写入；没有额外硬币、材料、经验、技能点或结局资格奖励。

旧存档无需额外迁移。保存沿用版本2的既有 flag 与足迹列表，正式发现记录的 `lore_1..3` 和旧手帐的 `history_0..2` 都可识别；新版不会凭空补齐缺失记录。已交回三枚星核的旧档可直接补看回信，无需重新交核。所有新操作在确认时重新核对：城镇、靠近莉雅、世界状态，且不在死亡或训练中；位置或状态变化后不能远程确认。

键鼠、数字选择、对话分页及手柄菜单沿用现有系统。可用 `tools/run_guild_story_checks.py --capture-dir .starfall-checks/layout` 留下生产输入、SaveStore 与 GUI 的离线证据；核心规则另由 `tools/run_core_tests.py` 和 Unity EditMode 包装覆盖。

本轮没有扩大地图或更换资源。现有 Campaign 与图集在启动时整套载入，世界逐格裁剪屏外地形，装饰与角色按脚底深度绘制；源码没有按区块延迟生成地图。后续地图扩展应先增加有路线、互动与隐藏发现的完整探索区，再依据原生剖析结果设计周边预加载与渐显边界。当前离线检查不能证明原生移动时无卡顿或 pop-in。
