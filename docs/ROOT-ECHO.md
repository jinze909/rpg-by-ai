# 地脉回声 / Root Echo

地脉深渊第 2、4 层的西北根系各有一次可选互动。清理本层后，可以领取补给，或自愿完成三轮脉冲挑战；也可以跳过，直接到原东门结算、选择祝福并深入。六层原地形、种子、敌人、收割者、出入口、祝福和结算奖励均保留。

## 选择与操作

- 根系位置 `(7, 9)`。在互动距离内按 E / 手柄 B，读完分页说明后选择。
- 补给回复最大生命的 25%，不超过最大生命；每个回声点只能选择一次补给或挑战收益。
- 挑战有三轮，各预告 1.25 秒，再留出 0.65 秒移动窗口。第一轮锁定起步位置；第二轮左右双圈留下中路；第三轮四角光圈留下中间空隙。正常步行即可离开第一圈，闪避沿用真实耐力、无敌与反击规则。
- 单次命中基础伤害为 `12 + 4 × 远征风险`，仍经过原难度、护盾、祝福等真实伤害规则；挑战不改变角色或普通战斗数值。
- 留在根系 4.5 格内；走远或在根系对话中取消，即可重新开始，不领取奖励。取消只移除本挑战的危险圈，不移除其他危险。
- 完成后获得额外硬币 20、碎片 `3 + 远征风险`，计入本层**未结算**收益。去原东门结算后才保留；死亡或从西侧提前离开仍沿用原未结算损失规则。

入口说明、清层通知和场景标识说明发现位置。危险圈沿用既有范围、倒计时、前景轮廓和 HUD 遮挡处理，最低特效和减少动态仍保留同样的危险信息。探索 HUD 显示当前轮次与提示；实际受击进入紧凑战斗 HUD 后仍显示轮次。

## 存档与生命周期

没有修改 SaveData 或存档版本。每层选择仅保存为 `abyss_echo_2` / `abyss_echo_4`，新远征清除这两个本轮选择。读档保留已完成选择及真实未结算收益；尚未完成的挑战安全取消，不恢复不可见的危险圈，也不补发收益。场景重建、远征结束、死亡恢复清理临时挑战。暂停、应用暂停和对话冻结真实计时。挑战进行中禁止结算或下层；可以取消后使用所有原出入口。

所有原美术、字体、金发主角身份、场景、Campaign、存档结构和既有 GUID 保持不变。新增文案只使用现有字体支持的中文字形，没有扩充或替换字体。

## 验证

`python3 tools/run_core_tests.py` 包含 7 组 Root Echo 检查：18 组跨种子六层保护、物理距离与过期选择、三轮真实危险圈、三职业×三风险、补给与旧存档、暂停/取消/死亡及真实伤害/闪避。

`python3 tools/run_root_echo_checks.py` 包含 4 组离线 Runtime 检查：实际 E/数字键分页、WASD/Space、真实接触与未结算结算、SaveStore 校验包与旧版 JSON、应用暂停和死亡、双语正常/大字界面。默认从 `tests/fixtures/root_echo_topology.json` 读取六层原始拓扑、装饰、敌人和出入口的固定快照，浅克隆 CI 无需历史对象。`--verify-baseline` 另从不可变 `3df9f32` 重新编译，核对该夹具来源。夹具是测试输入，不是运行日志。

`--capture-dir .starfall-checks/layout/root-echo` 可记录临时 OnGUI 布局。记录和重建预览属于离线验证，不代表 Unity GPU 实际画面。

Unity DLL 编译、核心/Runtime 检查不能替代原生导入、构建和试玩。原生验收仍为 **NATIVE_UNVERIFIED**，等待持证 Unity Editor。
