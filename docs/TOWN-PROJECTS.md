# 城镇建设：确认前查看材料与设施收益

城镇建设原来的三个按钮会立即消费材料并永久升级。现在从 B／城镇建设菜单或原镇内工程入口进入后，选择设施先查看建设计划，确认后才支付。不新增设施、材料或存档字段。

## 操作与显示

- 三个设施保持原位置。选择「查看计划」会显示当前→下一级效果、山野议会声望、设施总等级，以及木材、星晶、零件、硬币的支付后余额。不足的材料会显示具体差额。
- 「取消」默认获得键盘／手柄焦点，Esc／B 也只取消计划并留在建设菜单。鼠标、Tab／方向键／摇杆、Enter／A 都使用原菜单操作。
- 「确认建设」只在余烬镇、生命状态正常且材料齐备时可用。查看异地、满级或材料不足的设施仍能读到原因，但不能施工。
- 计划打开期间，底层菜单按钮、菜单快捷键和手柄肩键不会误触其他操作。失去焦点、更换菜单、读档、旅行、新游戏或更换游戏／存档对象会清除旧确认。
- 材料、硬币、设施等级、相关声望或边境协定变化后，旧计划不能支付；取消后重新查看即可。无关材料变化不会阻止一笔数值完全相同的交易。
- 查看或取消不治疗、不消耗、不推进世界、不改写已准备的攻击。确认施工也沿用原交易，不回复生命或耐力。

## 原设施成本与效果

| 升级 | 木材 | 星晶 | 零件 | 硬币 |
| --- | ---: | ---: | ---: | ---: |
| 0 → 1 | 4 | 2 | 3 | 30 |
| 1 → 2 | 6 | 3 | 4 | 50 |

每次建设仍增加山野议会声望1（上限10）。每项设施最多两级，满级不再收费。

- **水渠与药田**：每级收获额外2药草，二级解锁琥珀种遗物；预览同时计入供水协定原有的额外2药草。
- **远行驿站**：一级开放野外营地免费休整；二级在休整时每天赠一杯凉茶，沿用原每日记录。
- **记忆工坊**：一级开放遗物锻印；二级免除每次20硬币费用，仍需原有碎片与星晶。

原 `BuildProject(int)` 交易入口保留，正常建设仍使用相同成本与永久效果。菜单使用绑定当前 GameCore、SaveData、世界代数及相关数值的只读报价，不持久化确认对象。原 v1／v2 存档的设施、故事、装备、声望和记录保持兼容。

## 验证入口

- `python3 tools/run_town_project_core_checks.py`：报价、原交易与真实设施收益、过期报价拒绝、旧存档及战斗连续性。
- `python3 tools/run_town_project_checks.py`：实际 Update／OnGUI 的原入口、鼠标与键盘／手柄、默认取消、精确支付、暂停／失焦／旧会话、存档和双语布局。可通过 `--capture-dir` 导出离线绘制记录。
- 新检查接入完整 Core、Unity NUnit 包装及 GitHub Actions；相关天赋确认、锻印、厨房和任务回归验证共用菜单与设施接线。

离线运行、绘制命令预览和 Unity DLL 编译不是原生 Editor 导入、GPU 渲染、Player 构建或真实设备试玩；原生状态仍为 **NATIVE_UNVERIFIED**。
