# 普通敌人的有限追猎记忆

旧逻辑在每次可行动的帧都要求普通敌人与玩家距离不超过8格。绕水或墙的最短合法路径有时先远离玩家：溺水遗迹中，玩家在 `(8.5,4.5)`、追猎者在 `(3.5,10.5)` 时，敌人原本在警戒范围内，却会走出0.315格后停在距离8.01556格的位置，连续40秒不再接近。

本次让已发现目标的普通敌人保留有限记忆：

- 首次发现仍需要进入原来的 **8格** 范围，不扩大未警戒敌人的发现距离。
- 已发现目标后，普通敌人可行动时允许继续追至 **10格**；超过10格则停止追击。随后只有重新进入8格内才会再次启动。
- 后续的[脱战归位](ENEMY-RETURN.md)让原区域自然生成的普通敌人在丢失目标后走回驻守点。停止追击不再意味着这些敌人一直站在最后的位置；归位期间仍不恢复生命或推进攻击冷却。
- 正常格心目标继续使用原寻路；后续[屋后精确落点修复](ENEMY-FOOT-PATH.md)让区域普通敌人也能绕向合法但格心受阻的玩家落点。完整脚底碰撞与扫掠移动保留，不瞬移、不穿水、不提高速度，也不增加攻击距离。
- 原有蓄力、释放、受击与受控流程先执行，不取消或重新瞄准已承诺攻击。Boss仍使用原18格规则，基础教学、三段对练与试装训练使用原规则；Warden和试机守卫的专用AI不变。
- 追猎记忆仅属于当前 Enemy 实例。新生成、旅行或读档恢复的敌人没有继承警戒；相同敌人编号也不能借用已退休实例的记忆。暂停保留当前战斗，存档仍只写原 EnemyRecord 字段，不写警戒记忆。
