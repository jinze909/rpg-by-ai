# 最后一班巡路 · The Last Watch

一条接续序章旧信与返乡侦察员的可选支线。取得第一枚星核后，在余烬镇与归来的侦察员交谈，选择「最后一班巡路」。原有炖汤谢礼仍保留，主线与远岸剧情可继续进行。

先用星核能力打开密林西南旧路，调查原有补给箱中的巡路记录。已找回记录的存档直接进入守灯阶段。依次前往密林三处旧灯：`(7,12)`、`(18,18)`、`(23,9)`，按 E 阅读规则并开始守灯。

每处灯需要在 1.6 格的圈内连续守住 12 秒。敌人进入灯旁 3 格、角色离圈或受击会重置本次计时；暂停与菜单冻结计时。第一处吸引两名追猎者，后两处加入射手与重甲，考验绕侧、闪避、墙体挡箭和清理控制范围。可以先战斗清场，再回灯旁完成；稳灯成功只让本次支线敌人退去，不领取未击败敌人的掉落，也不移除原地图敌人。

三处灯都亮起后，回余烬镇向侦察员交付巡路记录，一次性获得 **40 硬币、4 碎片、1 技能点**。手帐新增「最后一班巡路」，金色导航和地图标记跟随记录、当前灯位与回城交付更新；现场显示灯号、范围、计时条和中断原因。

完成的灯永久保留。退出区域、死亡或读取会从零重新计算未完成灯的 12 秒守灯时间。已击败的支线敌人不会重复产出，当前地区存档保留存活敌人的 HP；跨地区重返会重新布置仍存活的成员。旧存档不自动接取、不自动发奖，保存格式仍为原有 v1/v2 与旗标、世界敌人快照。新敌人使用独立保留 ID 和非 Boss 身份，不设置主线 Boss／星核／结局旗标。

现有金发主角、全部原地图地形／道具／剧情／Boss／任务、角色图集、字体与既有 GUID 保留。新增灯复用已有灯柱美术；中文文案使用现有字体已收录的字形。无需新包、场景、Inspector 配置或外部服务。

验证入口：

- `tools/run_core_tests.py`：包含三职业编排战斗、完整支线、一次性领奖、旧存档、压力／暂停／死亡、残局恢复和主 Boss ID 隔离检查。
- `tools/run_watch_quest_checks.py`：实际生产 Update／OnGUI／SaveStore 的 E、R、数字对话、分页、J／Q／闪避／炖汤、手帐／地图／导航、应用暂停与重读。可加 `--capture-dir .starfall-checks/layout` 生成临时绘制记录。
- 现有战斗输入回归和编辑器离线语法／导入规则继续执行，CI 新增支线 Runtime 检查。

上述为实际生产代码的离线证据。Unity 编译、原生 GPU／音频／手柄、完整密林的节奏与玩家手感仍为 **NATIVE_UNVERIFIED**；没有把编排战斗的隔离测试称为原生试玩，也没有实测完成时长。
