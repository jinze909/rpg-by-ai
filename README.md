# 星陨边境 · Starfall Frontier

在原有 Unity 2D RPG 项目上实现的一款动作 RPG。以原 Viola 金发角色为共同主角，包含九个地区与炉火旅店、两条相互影响的剧情线、三职业、同伴、成长、制作与生活系统。

一颗星坠落后，森林狂暴、遗迹被淹、矿场不停运转。你接受公会委托寻找星核，却逐渐发现堡垒的屏障正在抽走边境的生命。

《远岸来信》扩展让你追查港口、沙海与高原的原始记录。守灯、救人、供水与公开真相都需要付出代价；你不仅要决定相信谁，还要建设足以兑现承诺的设施。

本轮继续检查延迟伤害与恢复状态，修复 Q 前摇/连锁击杀后属性变化、冰霜借用后来装备与位置、某些帧间隔多一次冰霜伤害、同伴替玩家完成教学，以及深渊操作打断死亡恢复。62组生产核心回归通过，含三职业18,000帧组合操作。复现与修复见 [DELAYED-SKILL-RECOVERY-BUGFIX.md](docs/DELAYED-SKILL-RECOVERY-BUGFIX.md)，最终验证见 [QA-REPORT.json](docs/QA-REPORT.json)。此前状态边界修复和全项目逐项复查继续保留。

三份镇民委托完成后，阿茴会邀请你准备「炉火共餐」：与杏、老潮、诺尔确认准备，在炉火旅店备餐、逐处送汤，并留下可重读的桌边故事。沿用原有生活玩法，支持分段存档与一次性报酬，见 [HEARTH-SUPPER.md](docs/HEARTH-SUPPER.md)。

完成杏与诺尔的委托后，可找诺尔接下「清水到药田」：从井东侧取水，送到药田边的试灌苗床，再向杏交回水桶，领取一次种子3与凉茶1。原种植和工程收益保留，每步都可存档后继续，见 [WATER-GARDEN.md](docs/WATER-GARDEN.md)。

世界地图新增「本地路标」：为已经探索的居民、营地、厨房、出口或机关设置独立路线，不更换当前追踪任务；路标随存档保留，清除即可恢复任务导航。其中「采集」分类可为已探索、尚未采完的木材、药草与矿石设路标，查看真实产出；采集后自动恢复任务路线。见 [LOCAL-LANDMARKS.md](docs/LOCAL-LANDMARKS.md)。

任务手帐的「查看目标地图」会临时显示所选任务的真实目标、标题与下一步，不再误用另一条追踪任务或个人路标。可直接返回手帐继续比较；查看不改追踪、不设路标、不自动旅行，Esc／手柄B仍按原规则返回世界。见 [LOCAL-LANDMARKS.md](docs/LOCAL-LANDMARKS.md)。

背包新增「材料来源」：按木材、星晶、药草、银鳍鱼、零件与种子查看已探索地区的真实获取方式，含动态购买价格、药田收获与成熟时间、矿石同时产出的星晶和零件。当前地区可主动设路标，其他地区可查看原地图后自行旅行；查看不花钱、不采集、不替换追踪任务。木材购买指向实际出售者阿茴。见 [MATERIAL-SOURCES.md](docs/MATERIAL-SOURCES.md)。

炖汤与凉茶生效时，探索和战斗 HUD 都显示剩余时间与真实收益：炖汤提供基础攻击+7，凉茶提供耐力回复+6/秒及暑寒保护。计时沿用原存档时钟，暂停不流失，休息照原规则消耗时间；不改原治疗、消耗或持续时间。状态框避让危险并允许鼠标攻击穿透。见 [PROVISION-STATUS.md](docs/PROVISION-STATUS.md)。

持短剑时，HUD显示当前普攻连段、下一招和剩余续招窗口；第三招明确区分起手与已释放。提示按原1.1秒时钟及已捕获动作读取，空挥也按原规则推进，不虚报命中；重斩倍率仍为1.25，费用和接触时刻不变。见 [SWORD-CHAIN.md](docs/SWORD-CHAIN.md)。

靠近资源、田地、旧路封印与补给箱时，E／手柄B提示会保留目标名称并说明当前状态，包括采集后的休息刷新、作物成熟倒计时、所需星核能力及补给记录重读。新增说明尽量避让HUD，原交互与奖励不变。见 [INTERACTION-HINTS.md](docs/INTERACTION-HINTS.md)。

闪避在开放地面固定移动2.7格，不再因帧率或末帧浮点余量额外滑出一段距离。方向捕获、原碰撞、耐力费用、无敌和冷却规则保留，见 [DODGE-INPUT.md](docs/DODGE-INPUT.md)。

地脉深渊第2、4层新增可选「地脉回声」：清层后可取一次生命补给，或挑战三轮有明确预告的地脉脉冲，获取本层未结算收益。支持取消重试、暂停和断点存档，六层原地图、敌人、Boss与结算不变，见 [ROOT-ECHO.md](docs/ROOT-ECHO.md)。

主角三种装备外观改为完整 256 图格，取消造成肩甲、弓弦和领口割裂的头身矩形拼接；固定脚底、原金发 Viola、22张图集注册及44张遮罩保留。正式路径使用 SpriteRenderer + Animator，并在原世界排序位置合成。运行中主角绘制失败会显示原始错误并停止模拟/保存；A–E 离线门槛含七项故障负向控制，编译检查覆盖隔离的 Player 分支。原生 Frontier 导入/试玩仍为 `NATIVE_UNVERIFIED`；实现与验收边界见 [HERO-ANIMATION-REBUILD.md](docs/HERO-ANIMATION-REBUILD.md)。历史尺寸、握持记录见 [FRAME-CONTINUITY-POLISH.md](docs/FRAME-CONTINUITY-POLISH.md)。

## 启动

1. **升级现有项目**：关闭 Unity，备份项目，覆盖包内 `Assets`、`Packages` 与 `ProjectSettings`；本轮也请更新 `ProjectSettings/ProjectVersion.txt`，清除旧的 C1 和 revision 信息。
2. 用国际版 **Unity 2022.3.53f1** 打开项目。版本文件只保留一行 `m_EditorVersion: 2022.3.53f1`。新建项目时选择 **2D / Built-In** 后关闭，再覆盖上述文件。若已能运行的国际版 2022.3 LTS 是其他补丁号，这一行填写它的真实版本号。
3. 导入结束后双击 `Assets/Scenes/Frontier.unity`，点击 Play；也可用 **Starfall → Play Adventure**。
4. 新游戏带八步入门与镇内三阶段实战练习；旧存档可直接继续，F1 随时查看十二类冒险指南。

默认构建场景已经切换为 `Frontier.unity`。原 `SampleScene.unity` 和原动画仍保留，供继续开发与比较。

菜单内方向键移动焦点，Tab循环、Enter确认、Esc返回。常见Xbox布局支持左摇杆移动、X攻击、A闪避、Y战技、B互动、LB炖汤、RB同伴指令、VIEW手帐、START暂停；菜单内A确认、B返回、LB/RB切换菜单。凉茶可在背包使用，完整说明及手柄实机验证范围见打磨文档。

闪避冷却结束前最后0.12秒内按一次空格／A或点击闪避格，会保留当时方向，在冷却转好后执行一次；不会提前扣耐力或进入无敌，也不会因按住按键连续闪避。暂停等边界会清除待执行操作，规则与验证边界见 [DODGE-INPUT.md](docs/DODGE-INPUT.md)。

战技冷却最后0.20秒内可按一次Q／Y或点击战技格预输入；真正就绪且动作可衔接时才按原费用起手，不提前扣费或施加防护。方向与目标按输入时保留，过早、过期或状态改变的请求不会延后自动施放，详见 [SKILL-INPUT.md](docs/SKILL-INPUT.md)。

普通攻击最后0.12秒内轻点J／手柄X／场景中的鼠标左键，会保留一次攻击及当时方向与目标；按住仍按原速度连攻，不会延长轻点缓冲。新的战技或闪避按键优先，菜单与切换场景会清除待执行攻击，详见 [ATTACK-INPUT.md](docs/ATTACK-INPUT.md)。

键盘快捷键或手柄View／Start打开菜单时，尚未起手的攻击、战技、闪避与同伴指令会先取消，避免在冷却刚结束的一帧先扣耐力。同帧的新操作也让位给菜单；已经开始的动作保留原暂停与继续规则。

主角实际扣血时显示带减号的浅红数字，反映难度、护盾与其他减伤后的生命损失；致死一击只计剩余生命，无敌闪避与安全训练不显示虚假扣血。数字与已有战斗浮字分开排布并自然消退，低特效保留同样信息。见 [COMBAT-TEXT.md](docs/COMBAT-TEXT.md)；原生验收仍为 `NATIVE_UNVERIFIED`。

有明确来向的实际受击，会在主角外侧短暂显示浅红描边记号，保留命中瞬间的方向；暑寒等无方向伤害不猜测方位。最低特效与减少动态保留静态提示，原扣血数字和操作保持不变。见 [HIT-DIRECTION.md](docs/HIT-DIRECTION.md)。

弓箭与星火在真正出手时，也会检测身体到武器前端之间的短路径，避免越过贴身敌人；射手的近身来箭遵守相同规则。墙体、原弹速、伤害、穿透与爆炸规则保留，已飞出的弹丸不会重复检测出手路径。见 [MUZZLE-CONTACT.md](docs/MUZZLE-CONTACT.md)。

同一弹丸采样点覆盖多名敌人时，按沿出手或飞行路径先接触的碰撞圆边界结算，避免敌人列表顺序让后排抢走普通箭或星火的直接命中。保留原碰撞范围、墙体裁切、贯穿与爆炸伤害规则，见 [PROJECTILE-ORDER.md](docs/PROJECTILE-ORDER.md)。

炖汤、米拉自动治疗与指令、遗物闪避与战技回血显示本次实际恢复的绿色数字，满血不显示虚假治疗，准备或排队阶段不会提前显示。炖汤提示改报真实恢复量，原有耐力回满与90秒攻击增益保留；所有治疗量、消耗和时机沿用原规则。

击杀奖励会显示短时战利品回执，合并近期击杀实际获得的硬币、经验与材料；深渊明确标为未结算收益，清层结算后清除旧提示。奖励、升级与存档规则保持，详见 [COMBAT-LOOT.md](docs/COMBAT-LOOT.md)。

同伴界面新增「同伴战术手册」，可查看当前羁绊下三种指令的具体效果、准备时间、冷却与作用位置。实际释放时显示短提示：米拉本次真实恢复量、伊沃射出的箭数、森生成领域与初始控制数量；保留原战斗规则与剧情通知。见 [COMPANION-TACTICS.md](docs/COMPANION-TACTICS.md)。

星术师寒星领域与森的指令各自完成五次原倍率脉冲，不再互相截断。领域位置、伤害归属与时钟独立，冻结时长不相加，原费用、起手与冷却保留；旅行和训练重置会清除全部旧领域。见 [BATTLE-PLANS.md](docs/BATTLE-PLANS.md)。

同伴指令支持冷却最后0.12秒的轻点预输入：Z／手柄RB和两个HUD布局都可提前记住一次请求，到期才按原前摇起手。保留按下时的瞄准、原18／12秒冷却及三位同伴的真实效果；不必一直按住或反复重按。见 [COMPANION-COMMAND-BUFFER.md](docs/COMPANION-COMMAND-BUFFER.md)。

同伴自动攻击会优先跟随玩家的有效锁定，但仍须满足同伴自身的视线与原7格射程；没有合适锁定时选择最近的活敌。米拉保持治疗优先，切换锁定不会改写已经准备或射出的攻击。空待不消耗自动支援间隔，就绪后走入射程或需要治疗时可直接准备；实际起手后的原间隔与释放时刻保留。

同伴跟随可绕过房屋，抵达「落点可站立但所在格中心被房屋占据」的位置，避免主角闪避绕屋后同伴一直卡在墙边。保留原跟随间距、速度、碰撞和出手站定，不通过瞬移追赶。见 [COMPANION-FOLLOW.md](docs/COMPANION-FOLLOW.md)。

完成遗潮档案与雾港调查后，可向露恩接取「第一封回信」：核对原册、听取港民回话、等待短光并交接回执，首次获得凉茶2与摆渡盟声望1。日志第二页可追踪，原有19项任务入口保持原位。见 [FIRST-REPLY.md](docs/FIRST-REPLY.md)；原生验收仍为 `NATIVE_UNVERIFIED`。

可选「战斗锁定」用 V、右摇杆按下 R3 或 HUD 按钮选择当前可见的敌人，边走位边对准同一目标。目标离开12格范围、被地形挡住或倒下时解除；新招式捕获当时位置，已发出的弹体继续按原轨迹飞行。锁定后可用 X／L3 顺序切换目标，Shift+X 反向；已起手招式和弹道保持原瞄准。见 [COMBAT-FOCUS.md](docs/COMBAT-FOCUS.md)。

## 可以玩到什么

新增可选支线 **最后一班巡路**：第一枚星核后找返乡侦察员，重读密林旧补给记录，再应对三处旧灯的混编敌人与连续守灯挑战，回城交付可获得一次性奖励。已点亮的灯可保存，手帐与金色路线跟随阶段更新，原有谢礼和剧情保留。玩法、存档边界及离线验证见 [LAST-WATCH.md](docs/LAST-WATCH.md)；原生试玩仍为 `NATIVE_UNVERIFIED`。

巡路交付后可挑战 **旧路守望**：第三处旧灯唤出守路回响，以直线冲刺、双灯光圈和留有中央空隙的散射考验闪避与反击。包含招式预告、手帐指引、存档续战、死亡重试及一次性奖励，沿用现有森林美术，独立于主线 Boss 进度。见 [SIGNAL-WARDEN.md](docs/SIGNAL-WARDEN.md)；原生战斗手感为 `NATIVE_UNVERIFIED`。

守望首胜后，第三处旧灯开放 **旧路复试**：以当前装备再次面对完整三招，记录本次用时、对守望者的实际伤害、破势和受击。正常承伤与消耗，不重复发奖；原森林和首胜结局保留。见 [WARDEN-REPRISE.md](docs/WARDEN-REPRISE.md)。

**阿茴的远行厨房** 把种植、钓鱼与采集材料变为三种互斥的180秒备餐：耐力回复、战斗减伤或普通步行速度。旅店厨师与有驿站补给的安全营地提供制作，HUD／背包显示余下效果；原炖汤、凉茶与赠礼保留，旧存档兼容。见 [ROAD-KITCHEN.md](docs/ROAD-KITCHEN.md)；原生验证为 `NATIVE_UNVERIFIED`。

**遗潮档案** 是沉水遗迹的新可选地牢：取得第二枚星核后，从遗迹入口进入，连接三处水轮、穿过交替冲水的小道，再找回三份记录并应对守卫。最后可选择公开记录或先送给家人核对；阶段可保存，报酬只领取一次，旧剧情与地图保留。见 [TIDE-ARCHIVE.md](docs/TIDE-ARCHIVE.md)；原生验证为 `NATIVE_UNVERIFIED`。

**双摇杆瞄准** 可让游侠与星术师边退边向前射击：右摇杆定方向，松杆后保留瞄准；左摇杆移动，闪避仍沿移动方向。暂停设置提供输入方案、上下反转与实时方向试验，键鼠可接回操作。见 [CONTROLLER-AIM.md](docs/CONTROLLER-AIM.md)；实体手柄与原生体验为 `NATIVE_UNVERIFIED`。

**艾妲的战术训练** 在原教官处追加三段可重复对练：追猎者的闪避反击、重甲的绕后与破势，以及射手与追猎者的混合战斗。使用正式战斗规则、真实命中反馈与当前装备；清场后手动前进，技巧次数只作反馈。生命与物资安全，世界时间暂停，退出或读档恢复开始状态；首次全程获得硬币25、技能点1。原教学与报酬保留。见 [SPARRING.md](docs/SPARRING.md)；原生体验为 `NATIVE_UNVERIFIED`。

- **六件遗物、两个槽**：治疗闪避、满血增伤、移动与耐力取舍、反击窗口、技能治疗与耗能取舍、暴击与承伤取舍。城镇记忆工坊用碎片锻印，最多三级。

## 验证与当前限制

`python3 tools/run_core_tests.py` 会编译实际 C# 游戏核心，执行全部生产核心回归检查；Unity EditMode 提供对应包装和额外原生 JSON 检查。需要 Python 3 和 Mono (`mono-mcs`)。包含原主线三职业标准难度通关、港口三个方案与三个协定、三职业六层深渊、和平解决原主线、地图可达性、潮汐安全、气候与凉茶、竞速、遗物取舍、专精、每日赠礼、交易、生活、旧存档迁移与深渊断点恢复。还包含实战教学、能力支路、武器打法、遭遇快照、菜单焦点、声音规则、接触时序、飞行物、死亡途中恢复、室内碰撞、同伴动作同步、物理攻击/闪避阻挡，以及出生脚底、涨潮前置、状态停止和历史缓存回归。新增战术训练涵盖三职业实战、反馈、经济隔离与返回存档边界；`python3 tools/run_sparring_checks.py` 另执行4组生产输入、GUI和存档检查。米拉新航线包含8组核心检查，`python3 tools/run_homeward_checks.py` 覆盖正式输入、同伴同行、交付／回话界面与存档路径。装备方案另含8组核心检查，`python3 tools/run_battle_plan_checks.py` 验证真实菜单、对练试用与存档。 明天的第一班另含10组核心检查，`python3 tools/run_commission_checks.py` 覆盖实际试机输入、预告与排压、两种供水决定、每日领取及旧存档兼容。 森的避风路另含10组核心检查，`python3 tools/run_shelter_trail_checks.py` 覆盖真实步行、横风命中与闪避、路线寒冷效果、双语界面和断点存档。 艾妲的实战记录另含10组核心检查，`python3 tools/run_fieldcraft_checks.py` 覆盖真实普攻／闪避、同发命中身份、制作换装、一次性交付、旧存档与双语反击界面。

也可在 Unity Test Runner 的 EditMode 中运行 `Starfall.Tests`。

`Starfall → Visual QA → Open Review Lab` 提供独立的职业/地区/Boss测试场，可冻结、逐帧推进、实战与原生截图；测试场不写入旅程存档。Test Runner 的 PlayMode 中另有 `Starfall.VisualTests`。本环境未执行这些原生测试。`python3 tools/check_editor_syntax.py` 只检查其离线 C# 语法。

当前环境尚未执行 Unity 原生验证。核心检查已经执行；运行时 C# 的离线语法与布局检查已执行。**这不是 Unity 编辑器编译、真实窗口试玩、音频试听或平台构建验证**。请打开上述场景完成这一步。

`python3 tools/run_layout_checks.py` 可重建生产 `OnGUI` 调用的离线布局预览，并执行真实临时目录中的存档文件恢复及菜单输入检查，需要 Mono、Python、Pillow 与 FontTools。`docs/previews` 展示新地图和中英文界面；字体指标、动画、音频和 Unity 的最终结果可能存在差异。数量与结果见 [docs/QA-REPORT.json](docs/QA-REPORT.json)。

## 项目结构

| 位置 | 用途 |
| --- | --- |
| `Assets/Scripts/Frontier/Core` | 独立于引擎的战斗、任务、成长、生活和存档数据规则 |
| `Assets/Scripts/Frontier/Runtime` | Unity 输入、像素场景、界面、音频、存档文件 |
| `Assets/Resources/Frontier/Campaign.json` | 地图、居民、交互物、Boss 与剧情数据 |
| `Assets/Editor/Frontier` | 场景启动、字体和图片导入、平台构建 |
| `Assets/Tests/Frontier` | Unity 与命令行共享的回归检查 |
| `Assets/Tests/PlayMode` | Unity 原生图集、方向动作、Boss时间线与截图检查 |
| `Assets/ArtSource/Frontier` | 本轮原始绘制图，不进入 Resources |
| `tools` / `tests` | 命令行测试与离线布局检查；不进入游戏构建 |

自动存档仍位于 `Application.persistentDataPath/starfall-v1.json`，手动位置位于 `starfall-slot-1.json` 至 `starfall-slot-3.json`。数据版本2，外层增加校验封套；原版本1/2的裸JSON可以读取并迁移。写入保留 `.bak`，读取可恢复有效备份或中断临时文件。独立调用存档规则时，先执行 `GameCore.PrepareSave()` 再序列化 `save`，以保存当前地区/深渊存活敌人和石碑进度。原角色脚本的移动、死亡、资源扣除等修复继续保留。
